# Конструктор ИД — инструкция пользователя

Версия 0.46.2 · 20.11.2026

## Что это за программа

«Конструктор ИД» собирает исполнительную документацию из одной книги Excel: данные объекта вносятся один раз, а акты, приложения, журналы и комплект для сдачи печатаются в PDF кнопками на панели.

Программа состоит из трёх частей:

- **Книга объекта** — обычный файл Excel с листами «Реквизиты», «Представители», «Материалы», «База актов» и другими. Все данные хранятся в ней: книгу можно копировать, пересылать и хранить как любой файл.
- **Панель «Конструктор ИД»** — надстройка справа в Excel. Она показывает карточку текущей строки, проверяет данные и запускает печать.
- **Сервер** — программа на вашем компьютере (окно «Konstruktor ID server»). Он печатает PDF через Microsoft Edge, собирает комплекты и обновляет справочник нормативов. Пока окно сервера открыто, печать работает.

Что печатает конструктор:

| Документ | Откуда берутся данные |
| --- | --- |
| АОСР — акт освидетельствования скрытых работ | «База актов», «Представители», «Реквизиты», «Исполнительные схемы» |
| РИМ — реестр использованных материалов | материалы акта (карточка акта), документы качества (лист «Материалы») |
| ВД — ведомость смонтированного оборудования | материалы акта (карточка акта), «ВОР» |
| ВОР — ведомость объёмов работ | «ВОР» |
| АВК — акт входного контроля | материалы акта и их документы качества |
| КЖ — кабельный журнал | «Кабельный журнал» |
| Протокол проверки сопротивления изоляции | «Кабельный журнал», «Изоляция» |
| Реестр ИД с титулом и корешками, комплект в одном PDF | «Комплекты», «Реестр ИД», сканы |
| Общий журнал работ, разделы 3 и 5 (приказ Минстроя № 1026/пр) | «База актов», «ОЖР Раздел 3», «ОЖР Раздел 5» |

Формы документов соответствуют образцам ООО «СБД».

## Установка и запуск

Программа ставится одним файлом «KonstruktorID-Setup-<версия>.exe» (около 42 МБ). Нужны Windows 10/11 и Excel 2021, 2024 или Microsoft 365 (Excel 2019 не подходит); больше ничего ставить не нужно, интернет не нужен. Права администратора не нужны, кроме корпоративного Office — см. ниже.

### Установка

1. Закройте Excel и запустите установщик (скачанный из Телеграма файл лежит в «Загрузках» или «Загрузки\Telegram Desktop»). Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае» (у установщика нет цифровой подписи).
2. На вопрос «Установить?» ответьте «Да». Когда Windows спросит про сертификат «Konstruktor ID Local CA», нажмите «Да» — без него панель не откроется. Сертификат действует только для адресов этого компьютера.
3. Закройте и снова откройте Excel. На вкладке «Главная» появится кнопка «Конструктор ИД» — она открывает панель справа.

**Корпоративный Office (LTSC 2021, 2019, 2024).** Такой Excel не видит надстройку, прописанную обычным способом, поэтому установщик подключает её через «общую папку»: кладёт файл надстройки в папку данных, открывает к ней общий доступ (Windows один раз попросит разрешение — «Да») и добавляет её в доверенные каталоги Excel. После установки один раз: «Вставка» → «Мои надстройки» → вкладка «Общая папка» → «Конструктор ИД» → «Добавить». Если прав администратора нет, установщик покажет, что попросить у IT: открыть общий доступ на чтение к папке `%LOCALAPPDATA%\KonstruktorID\catalog` под именем `KonstruktorID`.

Сервер работает в фоне без окна и сам запускается при входе в Windows. В меню «Пуск» → «Конструктор ИД» есть пункты «Перезапустить сервер», «Папка данных» и «Удалить Конструктор ИД».

### Обновление

Запустите установщик новой версии поверх старой и перезапустите Excel. Если установлена более новая версия, чем у установщика, он предупредит и по умолчанию предложит не ставить старую. С версии 0.32 разметка книги прежней версии обновляется сама при открытии панели: добавятся новые листы и столбцы, данные не изменятся (кнопка «Обновить разметку» появится, только если обновить не получилось).

### Где что лежит

| Что | Папка |
| --- | --- |
| Программа (окно программы — `KonstruktorID.exe`) | `%LOCALAPPDATA%\Programs\KonstruktorID` |
| Данные сервера: прикреплённые сканы, справочник нормативов, резервные копии, журнал сервера `server.log` | `%LOCALAPPDATA%\KonstruktorID` |
| Книги объектов | там, куда вы их сохранили |

Удаление программы («Пуск» или «Установка и удаление программ») книги и папку данных не трогает.

## Панель

Панель всегда показывает то, что выделено в книге: раздел текущего листа, инструменты и карточку строки под курсором. Она не хранит своих данных — всё читается из книги и пишется в неё.

### Верхняя строка

| Кнопка | Что делает |
| --- | --- |
| Книга | Разделы книги, карточки строк, печать документов акта |
| Печать и сдача | Комплекты (реестр собирается сам, «Сдать: собрать комплект» — один PDF), общий реестр, общий журнал работ, проверка всех актов перед сдачей |
| Помощник | Чат с нейросетью: заполняет книгу по тексту, проверяет акт, дополняет справочник, размечает формы заказчика |
| ▭ (Открыть в окне) | Тот же экран — в большом окне программы (см. «Окно программы») |
| ⚙ ▾ (Ещё) | Шаблон книги («СБД», «ТИ» или свой), «Редактор шаблонов…», «Поля для шаблона…», «Норматив» (справочник protect.gost.ru), «Библиотека компании», «Настройки» |

### Окно программы

С версии 0.36 у программы есть своё окно со значком на панели задач: ярлык «Конструктор ИД» на рабочем столе и в меню «Пуск» или кнопка ▭ в верхней строке панели. Слева — разделы (Книга, Печать и сдача, Помощник, Шаблоны, Поля, Норматив, Библиотека, Настройки), шаблон книги и название книги, справа — тот же экран, что в панели, только просторнее.

В окне есть экраны, которых нет в панели (0.37):

- «Объект» (открывается первым, 0.38) — наименование, шифры, шаблон и книга; сводка: акты (готовы, с замечаниями, не собираются), комплекты, документы качества (без скана, истекают раньше окончания работ), дни общего журнала работ; полоса готовности актов; «Требует внимания» — акты, которые не собираются, и замечания проверки перед сдачей (щелчок — к ячейке в Excel); кнопки «Спросить помощника», «Проверить акты», «Собрать комплект».
- «Акты» — все акты книги таблицей: поиск по номеру, работам и комплекту, отбор по статусу («готовы», «замечания» — предупреждения проверки перед сдачей, «не собираются» — печать покажет, что исправить) и по виду работ. Справа — карточка выбранного акта (материалы, подписанты, полнота, печать). Галочками выбирают несколько актов: «Печать выбранных (PDF)» — один документ (например, АОСР) всех выбранных актов одним PDF; «Файлы Word/Excel» — все документы выбранных актов одним архивом.
- «Печать и сдача» — комплекты списком слева, выбранный комплект в середине, общий журнал работ и проверка всех актов справа.

«Компактная панель» (меню ⚙ панели, 0.38): в панели Excel остаются «Книга» и «Настройки», а «Печать и сдача», «Помощник», шаблоны, норматив и библиотека открываются в окне программы. Выключается там же.

Книгу можно посмотреть и без Excel (0.39): если Excel с панелью не открыт, в окне есть кнопка «Открыть сохранённую книгу (.xlsx)…». Книга читается из файла только для просмотра и печати: работают «Объект», «Акты», «Печать и сдача» (печать документов, сборка комплектов, проверка перед сдачей), а изменения — «Следующий акт», «Обновить из актов», помощник — подскажут открыть книгу в Excel. Показывается то, что сохранено в файле: несохранённые правки из Excel в него не попадают. «Закрыть файл» — слева под названием книги.

Оформление окна (0.40): слева — книга объекта, разделы со счётчиками и мозаика готовности (квадрат на акт: зелёный — готов, жёлтый — с замечаниями, красный — не собирается); внизу — строка состояния: книга, объект, шифр, шаблон книги (выбор), сервер, версия. На «Объекте» — квадраты актов по порядку (наведение — что с актом, щелчок — акт на экране «Акты») и «Требует внимания» с местом в книге: лист · строка · столбец. На «Актах» — короткие номера, значок статуса, документы акта квадратами (пунктир — документ акту не нужен по «Виду работ»), поиск Ctrl+F; у выбранных актов — «Печать» (АОСР одним PDF), «В комплект…», «Проверить», «Файлы Word/Excel»; карточка акта — документы листами (щелчок — печать), замечания, подписанты по датам полномочий, «⋯» — полная карточка.

«Печать и сдача» в окне (0.41): слева — комплекты (акты, документы в реестре, замечания перед сдачей), «+ Новый комплект», карточки «Общий журнал работ» (печать разделов 3 и 5, обновление из актов) и «Общий реестр», число актов без комплекта. Справа — выбранный комплект: пять шагов сдачи (сверка с актами, проверка, печать, нумерация, один PDF), «Так будет сшит PDF» — листы по порядку с номерами страниц (по графе «Листов»; точно — при сборке), реестр комплекта (щелчок по строке — к строке в Excel), «Обновить из актов», «Проверить перед сдачей», «Сдать: собрать комплект».

«Книга» в окне (0.42): вкладки «Оглавление», «Реквизиты», «Представители», «Акты», «Материалы», «Схемы», «Кабельный журнал», «Комплекты», «ОЖР» (точка у вкладки — есть ошибки или замечания). «Оглавление» — разделы книги с числом строк и состоянием, «Листы Excel» (показать/скрыть лист, «Только нужные листы»), «Мастер первого акта», «Проверить книгу целиком». Вкладка раздела — три колонки: строки листа (поиск, «+ 1», «+ 10», копия, вверх/вниз, удалить с подтверждением), карточка выбранной строки (правка пишется в ячейку книги сразу при выходе из поля; пустые важные поля — розовые), справа — «Так акт будет напечатан» (первая страница АОСР), инструменты раздела, «Важные столбцы». «Реквизиты» — объект одной формой, организации и шифры.

В карточках «Книги» (0.43): у материала — количество по проекту, закрыто актами (полосой по актам) и остаток (перерасход — красным); у представителя — срок полномочий на шкале года и даты актов: попадают ли все акты в срок; на вкладке «ОЖР» — календарь дней работ (оттенок — сколько актов в работе в этот день; щелчок — запись дня).

Карточки «Книги» (0.44): поля сгруппированы по смыслу (у акта — «Основное», «Работы», «Требования и разрешение»; редкие поля — «Ещё N полей»), у каждого поля — адрес ячейки на листе (например, «D25»); обязательные отмечены красной звёздочкой. «Так акт будет напечатан» и «Шапка каждого акта» (на «Реквизитах») подсвечивают синим значения карточки в документе; «Где печатаются реквизиты». У схемы — скан справа (PDF или картинка), схемы того же акта листами, проверка схем книги и «Так в п. 4 акта» с выделенной строкой этой схемы. «Печать и сдача»: листы сканов в «Так будет сшит PDF» — точно по файлу; «Посчитать листы точно» печатает документы на сервере и ставит точные номера (после сборки комплекта — тоже).

Переход к месту исправления (0.45): щелчок по замечанию в окне («Требует внимания», карточка акта, проверка, ошибки печати) открывает «Книгу» на нужной строке и выделяет поле с ошибкой; ячейка выделяется и в Excel — скрытый лист (например, «Материалы в актах») при этом показывается. Документы акта: если у акта нет исходных данных документа (нет кабелей — КЖ и протокол изоляции, нет строки протокола), документ акту не нужен — он не показывается и не попадает в архив «Файлы Word/Excel»; документ, данные которого есть, но с ошибками, — красный, акт «не собирается», ошибки — в карточке.

Шаблон «Камчатка» (0.46): третий встроенный шаблон рядом с «СБД» и «ТИ» — формы объекта аэропорта Петропавловск-Камчатский. АОСР по 344/пр с номером акта без суффикса; п.3 — «Согласно реестра примененных материалов», п.4 — нумерованный список исполнительных схем, «Приложения» — «Согласно реестру приложений» (если в книге там своё значение — печатается оно). Реестр примененных материалов: строка документа качества (серая), под ней материалы с маркой. Реестр приложений: ведомость смонтированного оборудования, схемы («Приложение N», число листов — из новой графы «Листов» на листе «Исполнительные схемы»), затем документы качества с листами. ВД — «ВЕДОМОСТЬ № <номер акта>». Кабельный журнал СКС: шкафы группами, графы «№ ЗКУ», «№ шкафа», «№ п/панели», «№ порта на панели» → «№ роз.модуля» (новые столбцы «Кабельного журнала», пустые — берутся «Откуда»/«Куда»), марка, длины по проекту и фактическая, итоги по маркам, «Сдал:»; номер журнала — «Шифр журнала» из «ДокументыКабелей», иначе от номера акта. Новые столбцы появляются после «Обновить разметку». Встроенные шаблоны («СБД», «ТИ», «Камчатка») не меняются и не удаляются; любой шаблон, и встроенный, — «Выгрузить «…»» в файл .idk-template для другого инженера (у него встроенный загрузится копией «… (загружен)»).

Документы качества и схемы проверяются по загруженным файлам (0.46): скан есть, только если в графе «Скан» ссылка на файл (загружен через карточку, распознавание или библиотеку). Одно имя файла в ячейке без файла — «в «Скане» только имя … — файл не загружен»; у материала, у которого строки документов качества есть, но ни одного файла, — «нет загруженного документа качества». Так же считаются «без скана» на главном экране, в «Книге» и полнота комплекта.

Сканы в «Реестре ИД» (0.46.1): если скан схемы или документа качества загрузили после того, как реестр комплекта уже собран, «Заполнить из актов», «Проверить» и «Собрать комплект» переносят его в «Скан» реестра (раньше реестр с теми же документами не трогался и новые сканы в него не попадали). При сборке загруженный файл схемы или документа качества важнее имени, вписанного в реестр без файла; у документов качества с одинаковым номером («б/н») файл подбирается по виду и дате.

Документы в «Реестре ИД» (0.46.2): АОСР, РИМ (реестр материалов), РП и ВД попадают в реестр комплекта, только если они есть в шаблоне книги; схемы и документы качества — всегда. Если в выбранном для книги шаблоне их нет (например, шаблон создан кнопкой «Новый» и в него загружены только формы), «Печать и сдача» и сверка реестра прямо говорят, каких документов не хватает: выберите для книги шаблон с ними («Шаблоны» → «Выбрать для книги», например «Камчатка») или добавьте их в свой шаблон, затем «Обновить из актов». То же — в архиве «Файлы Word/Excel» акта: документов, которых нет в шаблоне, в нём нет, и карточка акта об этом пишет. Под ссылкой «Скачать» теперь перечислены файлы архива; документы, не вошедшие в архив (ошибки в книге или в своей форме), показаны списком с переходом к ячейке.

Предпросмотр документов в окне открывается поверх окна («Отдельным окном» — в своём окне, Esc — закрыть).

Окно работает с книгой, открытой в Excel: данные остаются в книге, правки из окна сразу видны в Excel и наоборот. Поэтому книга должна быть открыта в Excel, а панель «Конструктор ИД» в ней — тоже (её можно сузить). Если с панелью открыто несколько книг, книгу окна выбирают слева вверху; кнопка ▭ в панели переключает окно на книгу этой панели. Для окна нужен компонент Windows «Microsoft Edge WebView2 Runtime» (есть в Windows 10 и 11 с обновлениями).

### Разделы

Под верхней строкой (экран «Книга») — восемь разделов: «Реквизиты», «Представители», «Акты», «Материалы», «Схемы», «Кабельный журнал», «Комплекты», «ОЖР». Щелчок по разделу открывает его лист. У раздела из нескольких листов (например, «Акты»: «База актов», «Исполнительные схемы», «ВОР») над карточкой появляются кнопки перехода между листами. Лист «Материалы в актах» служебный: материалы акта отмечаются в карточке акта, а при «Только нужных листах» лист скрыт.

**Файлы Word/Excel** (0.35). В карточке акта рядом с кнопками печати — «Файлы Word/Excel»: все документы акта одним архивом для правки и отправки. Документы по своим формам — заполненными файлами Word (.docx) или Excel, как ваши образцы; встроенные — в Excel. У комплекта то же — «Скачать Word и Excel (архив)» в окне собранного комплекта.

**Следующий акт.** В карточке акта — «+ Следующий акт»: программа добавит копию последнего акта того же вида работ — номер +1 (нули сохраняются: «АОВ1.01.00.9» → «…00.10»), работы со следующего рабочего дня той же длительности, шифр, нормативы, подписанты и реквизиты ВОР — как в образце, схемы — с номерами +1 и датой нового акта (без сканов), материалы акта — те же, без количества. АВК не копируется. Проверьте «Работы (п.1)», даты и номера схем.

### Функционал листа

Работает со строками таблицы под курсором:

- **+1 / +10** — добавить строки под текущей; новая строка сразу получает значения по умолчанию (у акта — следующий номер, дату и подписантов ВОР);
- **Дублировать**, **↑ / ↓** — копия строки и перестановка; порядок строк важен: в нём материалы, схемы и строки реестра попадают в документы;
- **Удалить** — с подтверждением; если на строку ссылаются другие листы, панель скажет сколько и где;
- **Важные столбцы** — какие столбцы обязательны для печати (см. «Книга объекта»).

Если таблица отфильтрована, перед вставкой и перестановкой панель снимает фильтр, чтобы не задеть скрытые строки.

### Функционал таблицы

Список столбцов таблицы: точка — важный столбец, красная точка — он пуст в текущей строке. Щелчок переводит курсор в этот столбец.

### Карточка строки

Все поля строки с подсказками; «\*» — важное поле. Изменение в карточке сразу попадает в ячейку, и наоборот. Ссылки (организация, материал, акт) выбираются из списка, скан прикрепляется кнопкой.

При переименовании материала, акта, организации или ФИО панель предложит обновить ссылки на других листах. Под карточкой — действия раздела: у материала — его документы качества, у акта — переходы и печать, у комплекта — реестр и сборка.

## Книга объекта

Один объект — одна книга Excel. Данные лежат в «умных таблицах» на листах; панель связывает их по ключам: номеру акта, наименованию материала, краткому наименованию организации, ФИО.

### Создание книги

Откройте пустую книгу, панель и нажмите «Создать книгу объекта». Программа создаст листы и таблицы; в каждой таблице будет серая **строка-пример** (значение начинается с «Пример:»). Примеры не печатаются и не проверяются; замените их своими данными или удалите. При выделении любой ячейки Excel показывает подсказку, что в неё вносить.

### Листы

| Лист | Что на нём |
| --- | --- |
| Реквизиты | Объект (наименование, адрес, договор, участники, папка сканов, условия производства работ), Организации, Шифры рабочей документации |
| Представители | Подписанты по ролям, приказы, НРС, сроки полномочий |

| База актов | Акты: номер, дата, шифр, работы, даты, нормативы, подписанты ВОР, АВК |

### Подсветка и важные столбцы

- **Красный заголовок** — важный столбец: без него документ не напечатается. Список важных столбцов меняется кнопкой «Важные столбцы».
- **Розовая ячейка** — пустое важное поле в заполненной строке. В «Объекте» обязательны только наименование объекта, застройщик и лицо, осуществляющее строительство; договор можно не указывать.
- **Жёлтая ячейка** — повтор значения, которое должно быть уникальным (наименование материала, номер акта, краткое наименование организации). ФИО представителей может повторяться: один человек бывает в нескольких ролях.
- **Серый заголовок** — служебный столбец (считается сам или заполняется панелью).

### Обновление разметки

Если книга создана прежней версией программы или лист случайно удалён, панель покажет предупреждение с кнопкой «Обновить разметку». Она добавляет недостающие листы, таблицы, столбцы и значения списков и заново настраивает подсказки; данные не меняются.

Не переименовывайте листы, таблицы и заголовки столбцов: по ним программа находит данные. Свои столбцы и формулы справа от таблиц добавлять можно.

## Порядок заполнения

Заполняйте книгу сверху вниз по разделам: сначала справочники объекта, потом акты, которые на них ссылаются. Ссылки выбираются из выпадающих списков — их значения должны уже быть в своих таблицах.

1. **Реквизиты → Организации.** Краткое и полное наименование, ОГРН, ИНН, адрес, телефон, СРО. Из них собирается шапка АОСР и реестра. В «Логотип» — файл PNG или JPG для титула комплекта.
2. **Реквизиты → Объект.** Наименование, адрес, город, договор (необязательно), застройщик, лицо, осуществляющее строительство, проектировщик, выполнивший работы по умолчанию, папка сканов.
3. **Реквизиты → Шифры.** Шифр РД, наименование раздела (идёт в заголовок ВОР, АВК и титул), проектировщик.
4. **Представители.** Роль, должность, ФИО, организация, документ о полномочиях, НРС. «Действует с/по» — в акт попадают только действующие на его дату. «Порядок» — очерёдность внутри роли. Если строка в акте должна быть особой — впишите её в «Текст для акта».
5. **Материалы.** Наименование (уникальное, без «;»), марка, артикул, завод, единица. В той же строке — позиция РКЦ (см. «Спецификация проекта») и документы качества.
6. **Документы качества** — в строке материала, столбцы «Док.1: вид», «Док.1: номер», «Док.1: дата»… — до трёх документов на материал. Вид выбирается из списка, но можно вписать и свой — он так и напечатается в АОСР, РИМ, АВК и реестре. Можно вписать прямо в ячейки или из карточки материала: **«Новый документ…»** — вид (из списка или свой: просто впишите название, например «Санитарно-эпидемиологическое заключение» или «Протокол испытаний»), номер, дата (можно не указывать — будет «б/д»), срок действия, листы и скан, «Добавить» (документ ляжет в первую свободную группу «Док.N»). Общий сертификат на несколько материалов — те же вид и номер в строке каждого материала (и тот же скан, если он приложен); документы «б/н» без номера считаются разными, кроме случая, когда у них один и тот же скан; в карточке это **«Привязать имеющийся»**. **«Отвязать»** убирает материал из документа, у единственного материала — **«Удалить»** очищает его столбцы. Скан общего сертификата прикрепляется один раз — ко всем его материалам.
7. **База актов.** Номер акта без суффикса (программа добавит .АОСР, .РИМ, .ВД), дата, шифр, работы (п.1), листы и ревизия (п.2), даты работ (п.5), нормативы (п.6), разрешённые работы (п.7), подписанты ВОР. Новая строка «+1» сама получает следующий номер и сегодняшнюю дату.
8. **Исполнительные схемы.** Акт, вид («Схема» печатается как «Исполнительная схема №…», «Прочее» — как есть), номер, наименование, дата, скан. Порядок строк = порядок в п.4 АОСР.
9. **Материалы акта.** Встаньте на акт в «Базе актов» → в карточке **«Материалы акта ▾»**: найдите материалы, отметьте галочками, впишите количество (пусто — программа возьмёт сумму из ВОР) и № позиции → «Сохранить». Новые материалы встают в конец списка акта; порядок = порядок в п.3, РИМ, ВД и АВК. Строки хранятся на листе «Материалы в актах» — их можно вносить и править и прямо там. Встаньте на строку листа — в карточке на панели поле «Материал» с поиском: начните вводить часть наименования или марки (слова в любом порядке) и выберите из списка совпадений; так же работают «Акт» и другие поля со ссылкой на другую таблицу.
   В книге до версии 0.27 нажмите «Обновить разметку»: листы «Спецификация» и «Документы качества» сведутся в таблицу «Материалы» (позиции — к материалам с тем же № п/п РКЦ, документы — в группы «Док.N» их материалов, сканы — со ссылками). Старые таблицы сохраняются значениями на скрытом листе «Архив до 0.27». Если у материала было больше трёх документов или у документа не были указаны материалы — панель покажет их списком: внесите вручную.
10. **ВОР.** Акт, этаж или участок, материал, объём. Материал должен быть в «Материалах в актах» этого акта. При нескольких этажах ВОР добавит итоговый раздел.

В карточке акта кнопки «Схемы», «Материалы», «ВОР» показывают число строк акта и фильтруют соответствующий лист по этому акту.

## Печать документов акта

Встаньте на строку акта на листе «База актов» и нажмите на панели кнопку документа: «АОСР», «РИМ», «ВД», «ВОР», «КЖ», «Протокол» или «АВК».

1. **Проверка.** Программа проверяет всё, что нужно документу: важные поля, даты и числа, ссылки на существующие строки, повторы. Ошибки показываются списком «лист, строка, столбец: что не так»; щелчок переводит к ячейке.
2. **Предпросмотр.** Если ошибок нет, открывается окно с PDF и ссылкой «Скачать PDF». Из окна документ можно сразу напечатать.
3. **Excel.** Рядом всегда есть «Скачать Excel» — тот же документ файлом .xlsx с тем же именем. Он выглядит как PDF (линии, подписи, таблицы, лист А4), его можно поправить и распечатать из Excel. Для своей формы заказчика скачивается заполненный файл формы (для формы Word — «Скачать Word»). Строки с длинным текстом в Excel бывают чуть выше, чем в PDF, а страницы Excel разбивает сам; АОСР всегда начинается с п.1 на второй странице.

### Что учитывает печать

- **АОСР, п.3.** До пяти материалов — перечислены в акте с документами качества; больше пяти — ссылка на РИМ и ВД.
- **АОСР, п.4.** «Исполнительная схема» — перед первой из подряд идущих схем, как в образце СБД, или перед каждой — настройка шаблона («Редактор шаблонов», рядом с АОСР).
- **Подписанты** — из «Представителей» по ролям, действующие на дату акта, по «Порядку».
- **Подписанты для конкретного акта.** Если на акте один представитель заменяет другого (отпуск, смена ответственного), откройте карточку акта → блок **«Подписанты»** и отметьте, кто подписывает этот акт. Выбор действует на все документы акта — АОСР, РИМ, ВД, ВОР, АВК, кабельный журнал, протоколы — и на ОЖР (разделы 3 и 5), поэтому журнал сходится с актами. Роль, где никто не отмечен, подписывается как раньше — по датам «Действует с/по». Кнопка «по датам» возвращает роль к автоматическому выбору. Выбор хранится в столбце «Подписанты» на листе «База актов» (ФИО через «; »). Если у выбранного по датам нет полномочий на день акта, подпись всё равно будет — «Проверка перед сдачей» только предупредит.
- **РИМ.** Один документ — одна строка; наименование материала пишется один раз над всеми его документами. Документ на несколько материалов — отдельной строкой с их перечнем. Документ без даты — «б/д».
- **ВД.** Количество из «Материалов в актах», а если пусто — сумма по ВОР.
- **АВК** — акт входного контроля материалов акта: производитель, количество, документы качества; комиссия — подписанты ВОР. Номер по умолчанию — «01/АОВ1.01.00» (последняя часть номера акта и окончание шифра), дата — начало работ. Свои значения — в столбцах «АВК: номер» и «АВК: дата» «Базы актов».

Если сервер не запущен, панель покажет «Сервер не запущен»: выберите «Пуск» → «Конструктор ИД» → «Перезапустить сервер» и нажмите кнопку печати ещё раз.

## Проверка перед сдачей

В карточке акта — **«Проверить акт перед сдачей»**, в карточке комплекта — **«Проверить комплект перед сдачей»**. Программа ищет то, за что технадзор обычно возвращает ИД:

- срок действия сертификата или декларации истёк раньше даты акта;
- дата документа качества или схемы позже даты акта;
- у материала акта нет документов качества или нет количества (пусто и нет объёмов в ВОР);
- у документа качества или схемы нет скана, у документа не указано число листов;
- окончание работ раньше начала или позже даты акта, начало работ раньше даты договора, дата акта ещё не наступила;
- у роли подписантов нет представителя с действующими на дату акта полномочиями («Действует с/по»).

Это **только предупреждения**: печать, сборка и всё остальное работают как обычно. Щелчок по строке списка ведёт к ячейке, которую стоит проверить.

## Документы качества по сканам (несколько сразу)

На листе «Материалы», над карточкой строки, — **«Документы по сканам…»**. Выберите один или сразу несколько файлов (PDF, JPG, PNG). Для каждого программа покажет карточку: вид, номер, даты, листы и **материалы книги, к которым относится документ** — отмеченные она выбрала сама (по марке, артикулу, наименованию, изготовителю; с нейросетью — по её ответу). Проверьте поля и галочки, при необходимости добавьте материал поиском и нажмите «Добавить» (или «Добавить все»). Документ ляжет в свободные «Док.N» строк выбранных материалов, скан приложится. Если такой документ (вид и номер) в книге уже есть, программа не создаёт второй, а добавляет к нему выбранные материалы.

**Точность.** Распознавание Windows иногда путает буквы и цифры (О/0, З/3) — программа исправляет типичные ошибки в датах и предупреждает о невозможных датах (документ «из будущего», срок действия раньше даты). Точнее всего — с нейросетью, которая видит изображения (подключение «OpenAI-совместимая» с моделью Claude или GPT, «Локальная» с моделью для изображений): она получает сами страницы скана и читает реквизиты с них, а не из распознанного текста. YandexGPT и GigaChat получают распознанный текст.

## Документ качества по скану (из карточки материала)

В карточке материала нажмите **«Документ по скану…»** — то же, что выше, для одного документа: если он подходит и к другим материалам, карточка предложит добавить его и к ним. и выберите PDF или фото паспорта, сертификата, декларации. Программа прочитает документ и заполнит форму: вид, номер, дату, срок действия и число листов (по страницам файла). **Проверьте поля** и нажмите «Добавить» — документ ляжет в свободную группу «Док.N», скан приложится. Если в скане указан изготовитель, а в материале он другой или не заполнен, кнопка «Записать в материал» перенесёт его.

- PDF с текстом (например, выписка из реестра ФСА) читается сразу.
- Скан-картинку и фото распознаёт сам Windows — ничего ставить не нужно. Нужен русский язык распознавания: «Параметры → Время и язык → Язык → Русский → Параметры → Оптическое распознавание символов» (на русской Windows обычно уже есть). Распознаются первые 4 страницы.
- Если подключена нейросеть («Настройки → Нейросети»), поля из текста разбирает она; без неё — программа по своим правилам. Пустые поля, которых нет в скане, заполните вручную.
- Если скан не распознался, форма останется для ручного ввода, скан всё равно приложится.

## Кабельный журнал и протокол изоляции

Кабельный журнал (КЖ) и протокол проверки сопротивления изоляции печатаются на каждый акт из кабелей этого акта.

1. **Лист «Кабельный журнал».** Одна строка — один кабель: акт, группа (заголовок в журнале, необязательно), обозначение, откуда и куда, направление по планам, марка и длина кабеля, труба и её длина, примечание.
2. **Лист «Изоляция»**, четыре таблицы:
   - «Электролаборатория» — наименование и адрес, свидетельство, руководитель, проводивший испытания, скан;
   - «Средства измерений» — приборы с поверкой; все попадают в протокол;
   - «Измерения марок» — напряжение мегаомметра, допустимое сопротивление и значения на марку кабеля; они подставляются во все линии этой марки;
   - «Документы кабелей» — строка на акт: шифр и дата журнала, № протокола, даты измерений, условия, цель, нормативы, заключение.
3. **Собрать марки.** Кнопка «Собрать марки из журнала» в карточке кабеля добавляет в «Измерения марок» все марки журнала, которых там ещё нет (с умолчаниями 500 В и 0,5 МОм). Остаётся вписать значения.
   **Кабельные сборки** и другие марки, у которых сопротивление изоляции не измеряется: в «Измерениях марок» поставьте в столбце «В протокол» — «нет». Такие линии остаются в кабельном журнале, но в протокол изоляции не попадают (номера линий в протоколе идут подряд), значения измерений для них заполнять не нужно. Если в названии марки есть слово «сборка», «Собрать марки» сразу ставит «нет». В книге прежней версии сначала нажмите «Обновить разметку» — столбец «В протокол» появится в конце таблицы.
4. **Печать.** В карточке акта — «КЖ» и «Протокол».

- **КЖ** — листы А4 в рамке со штампом, по 30 строк. Если кабелей больше, добавляются листы с тем же штампом, «Лист» и «Листов» считаются сами. После кабелей — «ИТОГО» по каждой марке и «Всего». Подписи штампа — выполнившие работы и технадзор застройщика.
- **Протокол** — альбомные листы, строки идут подряд на любое число страниц, шапка таблицы на каждой. В конце — приборы и подписи лаборатории.

Перед печатью программа проверит: есть ли кабели акта, строка акта в «Документах кабелей», измерения на каждую марку, лаборатория и приборы.

## Реестр ИД и комплект в одном PDF

Комплект — это Том/Часть исполнительной документации из одного или нескольких актов. Программа собирает его в один PDF: титул → корешки → реестр → документы и сканы по порядку реестра.

1. **Сканы.** В «Объекте» укажите «Папка сканов» (например, `D:\Объект\Сканы`) и положите туда сканы схем, паспортов, сертификатов, свидетельств (PDF, JPG или PNG). В столбцах «Скан» достаточно имени файла; можно указать полный путь или прикрепить файл в карточке. Логотипы для титула — в «Организациях», столбец «Логотип».
2. **Комплект.** На листе «Комплекты»: № реестра, шифр (пусто — шифр первого акта), том, часть, корпус, перечень работ для титула, город, год, «Титул» и «Корешки» (да/нет), число частей в томе. Ниже, в «Актах комплектов», перечислите акты комплекта по порядку.
3. **Реестр собирается сам** (0.32). Откройте «Печать и сдача» (или карточку комплекта). Перед сборкой программа сверяет реестр с актами: если в актах появился или пропал документ, строки комплекта на листе «Реестр ИД» перестраиваются в порядке образца СБД (ВОР, АОСР, РИМ, ВД, схемы, КЖ, протокол, свидетельства о поверке и лаборатории, АВК, паспорта и сертификаты). Исправленные вручную «Листов», «Экз.» и сканы переносятся на те же документы. Если документы не изменились, лист не трогается. Сверить без сборки — «Обновить из актов».
4. **Сборка.** «Сдать: собрать комплект» сверит реестр, запустит проверку перед сдачей (предупреждения сборку не блокируют), проверит сканы, напечатает документы, посчитает листы и откроет один PDF. Если чего-то не хватает — список «Реестр ИД, строка N, «Скан»: Файл не найден…», щелчок ведёт к ячейке.
5. **Общий реестр.** Когда вся ИД подписана, нажмите в «Печать и сдача» **«Общий реестр»**: программа сверит реестры всех комплектов с актами и соберёт реестры всех комплектов книги в один — по группам «Реестр №… Том … Часть …», документы подряд со сквозной нумерацией, с листами и итогом. Откроется предпросмотр PDF, рядом — «Скачать Excel». Если у какой-то строки не найден скан, она останется в реестре с листами из графы «Листов», а панель перечислит такие строки.

Листы документов нумеруются с ВОР = 1 в правом нижнем углу; номер совпадает с «л. N» в реестре. Титул, корешки и реестр не нумеруются. Графа «Листов» реестра берётся из документа, если не задана в строке. Собранный комплект доступен 30 минут: если окно предпросмотра пустое, нажмите «Открыть в браузере» или «Скачать PDF». «Скачать Excel (архив)» даёт .zip с файлом Excel на каждый документ реестра по порядку («01 …», «02 …»); сканы в архив не входят.

## Спецификация проекта (РКЦ)

Спецификация показывает по каждой позиции проекта: сколько всего по проекту, сколько закрыто актами и сколько осталось.

Позиция РКЦ — это столбцы «№ п/п РКЦ», «Раздел», «Кол-во по проекту», «Закрыто», «Остаток», «Источник», «Примечание» в строке материала на листе «Материалы». Если у позиции несколько материалов (кабель разных марок), у всех один № п/п, а «Кол-во по проекту» — в первой строке; итог позиции — в карточке материала.

1. Раздел «Материалы» на панели → «Загрузить из РКЦ» → выберите файл расчёта коммерческой стоимости (.xlsx) и лист (например, «д.с.1») → «Разобрать». Программа найдёт шапку «№ п/п — Наименование — Ед. изм. — Кол-во», разделы и позиции; итоги, НДС, аванс и цены не переносятся. Файл .xls сначала сохраните в Excel как «Книга Excel (*.xlsx)».
2. Проверьте предпросмотр: сколько позиций новых, изменённых и пропавших из РКЦ, и предупреждения (позиция без номера получает «б/н-1», повтор номера — «-2», пустое количество — 0). «Применить» запишет позиции в «Материалы»: существующие — по № п/п (материалы не удаляются и не переименовываются; новое наименование из РКЦ попадёт в «Примечание»), новые — новыми строками.
3. Доп. позиции добавляйте обычной строкой: свой номер (например, «доп-1»), «Источник» — «вручную».
4. Привяжите материалы: столбец «№ п/п РКЦ» — номер позиции. Кнопка «Подобрать № п/п» на листе «Материалы» предложит номера по сходству наименования и марки: отметьте верные и нажмите «Применить отмеченные». Сложные случаи можно отдать Claude — он заполнит столбец в присланной книге.
5. «Закрыто» и «Остаток» считаются сами (по материалу строки): в «Закрыто» идёт «Кол-во» строки «Материалов в актах», а если оно пустое — сумма ВОР. Отрицательный остаток (закрыто больше, чем по проекту) — красным.
6. Карточка материала с № п/п и карточка строки «Материалов в актах» показывают по позиции целиком по проекту / закрыто / остаток и разбивку по актам. В карточке акта есть предупреждение о материалах без привязки — печать оно не блокирует.
7. «Обновить лист «Закрытие по актам»» строит отчёт: позиции по разделам и по столбцу на каждый акт — для сверки и для заказчика.

Новое доп. соглашение загружайте так же: позиции обновятся по № п/п, строки «вручную» и привязки материалов останутся, а позиции, которых нет в новом РКЦ, получат пометку «нет в РКЦ» в «Примечании».

## Общий журнал работ

Программа заполняет из актов разделы 3 и 5 общего журнала работ по форме приказа Минстроя России от 02.12.2022 № 1026/пр и печатает их листами для журнала. Титульный лист и разделы 1, 2, 4, 6 ведутся как обычно.

1. В «Объекте» заполните «Условия производства работ», например «Температура воздуха +18 °С, в помещении».
2. У актов должны быть «Начало работ» и «Окончание работ» и подписант «ВОР: от монтажников».
3. «Печать и сдача» (или раздел «ОЖР») → «Печать раздела 3» / «Печать раздела 5». Перед печатью журнал сам сверяется с актами и перестраивается, если акты изменились; PDF откроется по форме приказа. Акты без дат работ панель покажет списком.
4. Поправить листы (например, условия в дни с другой погодой) можно в любой момент — исправленные условия сохраняются для тех же дат. Сверить без печати — «Обновить из актов».

| Лист | Что там | Как заполняется |
| --- | --- | --- |
| ОЖР Раздел 3 | Сведения о выполнении работ | Строка на каждый день работ актов, кроме воскресений; даты и номера идут подряд без повторов. Работы дня — п.1 актов по порядку «Базы актов», каждая с новой строки. Представитель — подписант ВОР от монтажников; если в день работают разные подрядчики — все. |
| ОЖР Раздел 5 | Перечень исполнительной документации | АОСР с приложениями (РИМ, ВД), отдельной строкой — ведомость смонтированного оборудования (ВД), исполнительные схемы, АВК, КЖ, протокол изоляции — по дате подписания, с должностями и фамилиями подписавших. Лист сверяется с актами сам перед каждой печатью. |

Когда акты меняются, оба листа строятся заново: исправленные условия сохраняются для тех же дат, остальные ручные правки пропадают. Воскресенья и нерабочие праздничные дни (ст. 112 ТК РФ, с переносами по постановлениям Правительства) пропускаются автоматически; если работали в такой день — добавьте строку вручную. По порядку ведения журнала раздел 3 заполняется в день выполнения работ, раздел 5 — не позднее следующего дня после подписания документа.

## Норматив

Вкладка «Норматив» — справочник нормативов портала protect.gost.ru: своды правил, ГОСТ, правила, классификаторы, технические регламенты и основополагающие стандарты (около 5000 документов) с наименованиями и статусами. Тексты нормативов программа не хранит: документ открывается на самом портале.

- **Обновить базу** — загружает списки с портала (нужен интернет, несколько минут). Делайте это иногда, чтобы статусы были актуальны.
- **Поиск и разделы** — по обозначению и названию, фильтр по разделу.
- **Читать** — открывает карточку документа на protect.gost.ru; вход на портал вы выполняете сами. **Карточка** — сведения о документе на панели.
- **В ячейку** — вставляет норматив в активную ячейку (обычно п.6 акта) через запятую. Переключатель «Вставлять»: только обозначение («СП 76.13330.2016») или обозначение и наименование («СП 76.13330.2016 "Электротехнические устройства"»). Если норматив уже есть в ячейке, панель скажет «Уже есть в ячейке».

## Свои шаблоны

Шаблон — это набор документов с их формами. Встроенный «СБД» не меняется; свой шаблон делается из него кнопкой «Копия».

1. «⚙ ▾» → «Редактор шаблонов…». Выберите «СБД», впишите имя (например, «Заказчик ПИК») и нажмите «Копия», затем «Выбрать для книги» — шаблон запомнится в книге объекта.
2. Документы шаблона: уберите ненужные («Убрать»), добавьте встроенные («Добавить встроенный») или свои — «Добавить свой документ» с названием и коротким кодом (например, «Акт гидравлических испытаний», код «АГИ»; номер документа будет «номер акта.АГИ»). Стрелки ↑↓ задают порядок кнопок печати и строк реестра ИД.
3. Своя форма — документ Word (.docx) или Excel (.xlsx) с метками вместо значений. Все метки — в «⚙ ▾» → «Поля для шаблона…»: там видно, что подставится на выбранном акте, и есть кнопка «Копировать». Например: «Акт № {Акт.Номер АОСР} от {Акт.Дата}», «{Технадзор.Подпись}». Чтобы строка таблицы повторилась по материалам акта, начните её с «{#Материалы}» и закончите «{/Материалы}», а в ячейках поставьте «{Материал.Наименование}», «{Материал.Кол-во}» и т.д. Так же работают «Схемы» и «ВОР». Готовый файл — «Загрузить форму».
4. По образцу: если у вас есть заполненный документ, выберите внизу акт, по которому он заполнен, и нажмите «По образцу» у нужного документа. Программа заменит значения этого акта метками, а строку с первым материалом сделает повторяющейся. Если одно значение подходит к нескольким полям (например, одна дата у акта и окончания работ), выберите нужное в списке. «Скачать для проверки» откроет результат в Word; «Сохранить форму» прикрепит его к документу.
5. Печать: в карточке акта кнопки идут по документам шаблона; у документа со своей формой — значок ✎. PDF делает установленный Word или Excel — печать совпадает с тем, что вы видите в Word. Если Office нет, программа печатает сама и предупреждает, что форма может отличаться. После печати есть ссылка «скачать файл для правки» — заполненный .docx/.xlsx.
6. Свои документы попадают в реестр ИД и в комплект сами.

7. **Бланк.** У встроенных документов с таблицей (РИМ, ВД, ВОР, АВК, протокол изоляции; ВД, РМ, РП и КЖ «ТИ»; протоколы и акты комиссии) есть кнопка «Бланк ▾»: снимите галочку графы, чтобы её не печатать, впишите свой заголовок графы, уберите необязательные строки (например, запас в строках марок и «Сдал/Принял» в КЖ «ТИ»). «Исходный вид» возвращает бланк образца. Настройка действует на PDF и Excel. АОСР и кабельный журнал «СБД» заданы нормативом и не настраиваются. То же можно попросить у помощника.

8. **Загрузить формы заказчика** (0.34; с 0.35 — сразу несколько файлов, в том числе старые .doc и .xls: их переводит в .docx/.xlsx Word или Excel на компьютере, вёрстка не меняется) — вверху «Редактора шаблонов». Выберите заполненные документы заказчика — больше ничего делать не нужно: программа сама узнаёт, что это за документ (по заголовку: АОСР, РИМ, ВД, ВОР, АВК, КЖ, протокол из справочника или свой — тогда предложит название и код, например «Акт гидравлических испытаний» → «АГИ»), находит акт книги, по которому образец заполнен (больше всего совпавших значений), ставит метки и спрашивает только о спорных местах (например, одна дата и у акта, и у окончания работ). Если вид определён неверно — выберите другой в списке «Это …», разметка повторится. «Скачать для проверки» откроет форму с метками в Word/Excel; «Сохранить форму» прикрепит её к документу шаблона (встроенный документ будет печататься по ней, свой — добавится). Для встроенного шаблона сразу создаётся копия «… (свои формы)» и выбирается в редакторе. «Сохранить все» сохраняет все распознанные формы разом.
   Метки ставятся по значениям акта из книги, поэтому сначала внесите в книгу акт, которым заполнен образец (помощник: «Заполни книгу по этому файлу»). Короткие общие значения — город, месяц, год — метятся, только если встречаются в документе один раз (иначе они попали бы и в адреса, и в даты приказов). Дату, разбитую по ячейкам («23» | «марта» | «20» | «26» г.), программа не узнает — поставьте метки {Акт.День}, {Акт.Месяц}, {Акт.Год} в Word вручную или попросите помощника. Для своих таблиц есть списки: «Материалы» (ведомость), «Реестр» (документ качества и под ним его материалы — как в реестре применённых материалов заказчика), «Приложения» (реестр приложений к АОСР), «Кабели» (кабельный журнал), «Схемы», «ВОР». Полные реквизиты организаций, как в шапке АОСР, — поля «Объект.Застройщик реквизиты», «Объект.Строительство реквизиты», «Объект.Проектировщик реквизиты».

9. **Оформление** (0.33). У каждого встроенного документа (включая АОСР и КЖ) есть кнопка «Оформление ▾»: шрифт (Times New Roman, Arial, Calibri, Cambria, Courier New, GOST type A), размер основного текста, текста таблиц, заголовков граф и заголовка документа (пт), жирный и курсив заполненных значений, межстрочный интервал, наименьшая высота строки таблицы (мм), выравнивание в таблице, текст по ширине, поворот заголовков узких граф (снизу вверх), поля листа (мм) и ориентация. Пустое поле — как в образце. «Набор» сразу ставит готовый вариант: «Крупнее», «Компактно», «Arial, без курсива», «ГОСТ: Times 12, поля 20/10/10/30» — затем его можно поправить.
   Ниже — **предпросмотр на акте книги**: документ меняется сразу при правке (программа сама берёт первый акт, который можно напечатать; другой — в списке). «Сохранить» записывает оформление в шаблон (у встроенного «СБД» — в его копию, выбранную для книги), «Отменить правки» возвращает сохранённое, «Как в образце» — исходный вид. Оформление действует на PDF всех актов книги с этим шаблоном и на собранный комплект; в Excel — шрифт, размеры, поля и ориентация. Помощнику можно сказать: «сделай ВД шрифтом Arial 9», «в АОСР значения без курсива», «КЖ на альбомном листе, поле слева 25 мм» — он предложит изменение, вы подтвердите.

Шаблоны хранятся на этом компьютере и доступны в любой книге. «Выгрузить» сохраняет шаблон с формами в файл .idk-template, «Загрузить шаблон» — добавляет его на другом компьютере. Если книгу открыли там, где её шаблона нет, программа печатает по «СБД» и предупреждает об этом.

Ширина панели запоминается только в Excel 2507 и новее (Microsoft 365): после перезапуска панель откроется той же ширины. В более ранних версиях Excel надстройка не может задать свою ширину — «Настройки» → «Панель» покажет, как у вас. Если панель узкая (меньше 400 точек), кнопки верхней строки и разделы показываются значками; подпись видна при наведении.

## Наборы форм: как поменять форму документа

Форма документа (ВД, реестр материалов, кабельный журнал, реестр ИД) выбирается в шаблоне, данные книги остаются те же.

1. «⚙ ▾» → «Редактор шаблонов…» → выберите шаблон.
2. **Набор форм и нумерация:** «СБД» или «ТИ». От набора зависят формы и номера: в «ТИ» АОСР — просто номер акта,
   приложения — «номер.РМ», «номер.РП», «номер.ВД», «номер.КЖ», протокол — «номер.П».
3. Чтобы взять у одного документа форму другого набора — у документа в списке «Форма:» выберите нужный набор
   (например, ВД по «СБД», а остальное по «ТИ»). «по набору» — как выбрано в п. 2.
4. **Реестр ИД: форма** — вид реестра в комплекте («ТИ» — с графой «Страницы по списку» и «Сдал/Принял»).
5. У кабельного журнала «ТИ» — «Запас, %»: фактическая длина каждой марки в строке «в т.ч. <марка> с учетом кф запаса N%» печатается уже с запасом (вверх до целого метра); отдельной строки запаса нет. Рядом — «Знаков после запятой в итогах»: 0–3 знака для «Итого всего» и строк «в т.ч. <марка>» (как кнопки разрядности в Excel: по правилам округления, нули дописываются; длина с запасом — вверх до этого знака). «Как посчитано» — прежний вид. Длины кабелей в строках журнала печатаются как в книге.
6. «Выбрать для книги».

«СБД» и «ТИ» — встроенные и не меняются: если поменять в них набор или форму, программа сама сделает копию
«… (копия)» с вашей настройкой и откроет её. Для КЖ «ТИ» заполните в «Кабельном журнале» столбцы «Длина по проекту»,
«Лоток», «Труба гладкая», «Труба гофрированная» (если не заполнены — фактическая длина берётся из «Длины»). Книгу
старой версии сначала обновите: «Обновить разметку».

Если подходящей формы нет ни в одном наборе — загрузите свою форму «По образцу» или пришлите образец разработчику:
он добавит её как ещё один вариант.

## Протоколы испытаний и акты приёмки

Программа печатает 16 протоколов и актов, которые раньше нужно было делать вручную или ждать сканом:

- **протоколы лаборатории** — испытание силовой кабельной линии (ПКЛ), проверка автоматических выключателей (ПАВ), устройств защитного отключения (ПУЗО), цепи «фаза — нуль» (ПФН), металлосвязи (ПМС), сопротивление заземляющего устройства (ПЗУ), затухание оптических волокон (ПЗОВ), тестирование СКС (ПТСКС);
- **протоколы и акты комиссии** — осмотр (ПОКБ) и прогрев (ППКБ) кабелей на барабанах, испытание трубных проводок (АТП), приёмка после индивидуального испытания (АИИ), техническая готовность к комплексному опробованию (АТГ), сдача-приёмка ПНР (АПНР), окончание монтажа систем автоматизации (АОМА), проверка работоспособности пожарной сигнализации (АРПС).

Как заполнить:

1. На листе **«Протоколы и акты»**, в таблице «Протоколы», добавьте строку документа: «Документ» (код из списка), «№ документа», дату. Документ «на акт» (ПКЛ, ПОКБ, ППКБ, АТП, ПЗОВ, ПТСКС) — укажите «Акт». Документ «на комплект» (ПАВ, ПУЗО, ПФН, ПМС, ПЗУ и акты приёмки) — «Комплект» (или любой акт этого комплекта). Нормативы и заключение можно не заполнять: программа подставит нормативы из справочника и обычное заключение.
2. Замеры внесите на листах **«Замеры электрики»**, **«Барабаны и трубы»** или **«Замеры СКС и ВОЛС»** — в таблицу этого документа, в столбце «№ документа» — номер из шага 1.
3. Столбец «Результат» можно оставить пустым там, где программа считает сама: время срабатывания автомата, ток срабатывания УЗО, ток КЗ петли, сопротивления металлосвязи и заземления, затухание волокна, запасы линии СКС. Где посчитать нельзя (испытание кабельной линии, трубные проводки, барабаны) — впишите результат. Если хоть одна строка «не соответствует», впишите своё заключение — иначе программа не напечатает документ.
4. Протоколы лаборатории подписывают руководитель и испытатель с листа «Изоляция», там же — средства измерений. Акты комиссии подписывают представители с листа «Представители» по ролям документа (технадзор, строительство, выполнивший работы, проектировщик — что есть).
5. Акты приёмки (АИИ, АТГ, АПНР, АОМА, АРПС): перечень оборудования — таблица «ПереченьОборудования» на листе «Протоколы и акты». Пусто — программа возьмёт материалы из «Материалов в актах» (акта или всех актов комплекта).
6. Печать: документы «на акт» — кнопками в карточке акта, «на комплект» — в карточке комплекта, блок «Документы комплекта». В реестр ИД они попадают сами (вид «Акт/протокол»), в собранный комплект — с номерами листов.

Своя форма: «Редактор шаблонов» → у документа «Образец .docx» — Word с метками (`{Документ.Номер}`, строка таблицы `{#Строки}…{/Строки}`, подписи `{#Комиссия}…{/Комиссия}`). Поправьте в Word и загрузите кнопкой «Загрузить форму».

## Справочник и полнота

Справочник подсказывает, какие документы исполнительной документации нужны для каждого вида работ, и следит, чтобы ничего не забыли. Документы в нём — по приказу Минстроя № 344/пр и сводам правил (СП 76.13330, ПУЭ гл. 1.8, СП 77.13330). Сейчас в справочнике электромонтаж, электроснабжение, слаботочные системы и связь, автоматизация и пожарная сигнализация.

1. Шаблон из справочника: «⚙ ▾» → «Редактор шаблонов…» → свой шаблон (копия «СБД») → «Из справочника». Отметьте виды работ, которые вы делаете на объекте, — их документы добавятся в шаблон. Документ, нужный нескольким видам работ, добавляется один раз. Если снять галочку, программа предложит убрать документы, которые больше никому не нужны.
2. Документы встроенного справочника печатает программа (АОСР, РИМ, ВД, протоколы и акты приёмки и др.). В свой шаблон можно добавить и свои документы: «форма» — для неё загружается форма Word/Excel (см. «Свои шаблоны»); «скан» — документ, который делаете не вы: программа его не печатает, а ждёт файл. Документ может быть «на акт» или «на комплект» — тогда он один на весь комплект.
3. В «Базе актов» укажите у акта «Вид работ» (из списка; несколько — через «; »). Акт без вида работ получает все документы шаблона. Столбец «Без документов» — коды документов, которые этому акту не нужны.
4. В карточке акта блок «Полнота» показывает каждый нужный документ: «печатается», «скан есть», «нет скана», «нет формы» или «нет данных» (у протокола или акта нет строки на листе «Протоколы и акты»). Кнопка «не нужен для этого акта» запишет документ в «Без документов».
5. Скан указывают в реестре ИД, в столбце «Скан» строки с номером «номер акта.код» (для документа на комплект — просто «код»).
6. Перед сборкой комплекта программа пишет «Не хватает документов: N» — это предупреждение. Но если у строки «скан» нет файла, комплект не соберётся: «Нет скана: укажите файл в столбце «Скан»».

Ведомость объёмов работ (ВОР) в справочник не входит. Если она нужна, добавьте её в шаблон вручную: «Добавить встроенный» → «ВОР». Свои документы и виды работ справочника хранятся на этом компьютере и переносятся вместе с выгруженным шаблоном.

## Помощник (нейросеть)

Помощник выполняет задачи, написанные словами. Он работает только с данными программы: книгой объекта, справочником, формами и бланками шаблона. Изменения он **предлагает**, а вносите их вы.

### Подключение

«Настройки» → «Нейросети» → добавьте подключение и сделайте его активным:

| Вид | Что указать |
| --- | --- |
| YandexGPT | Ключ API сервисного аккаунта и ID каталога Yandex Cloud. Модель по умолчанию — `yandexgpt/latest` этого каталога. |
| GigaChat | Ключ авторизации из личного кабинета Сбера и область (`GIGACHAT_API_PERS` для физлиц, `…_B2B` / `…_CORP` для компаний). Серверы Сбера работают на сертификате Минцифры: скачайте «Корневой сертификат Минцифры» на Госуслугах (gosuslugi.ru/crt) и укажите путь к файлу в поле «Файл корневого сертификата». |
| Локальная модель | Адрес Ollama или vLLM (по умолчанию `http://localhost:11434/v1`) и имя модели. Данные никуда не уходят. |
| OpenAI-совместимая | Адрес API, ключ и модель (DeepSeek, OpenRouter и т. п.). По умолчанию включено «Не отправлять ФИО»: вместо фамилий модель видит «[ФИО-3]», а в правках программа подставляет имена обратно. |

Кнопка «Проверить» отправляет короткий запрос и показывает ответ или ошибку. Ключи хранятся только на этом компьютере. Внизу показан расход токенов за месяц по каждому подключению.

### Работа

1. Верхняя строка → **«Помощник»**. Напишите задачу, например:
    - «Проверь акт ЭОМ-1 — чего не хватает для печати?»
    - «Добавь акт на прокладку кабеля на П3 по образцу акта АОВ1.01.00.1, даты 10–12 ноября»
    - «Поменяй в актах раздела ЭОМ норматив п.6 на СП 76.13330.2016»
    - «Добавь вид работ “Монтаж СКУД” с актом проверки контроллеров»
2. Помощник читает книгу, затем отвечает и показывает карточку **«Предлагаемые изменения»**: что добавить, что изменить («было → стало»), что удалить. Снимите галочки с ненужного и нажмите **«Применить»**. Кнопка **«Отменить применённое»** вернёт всё как было.
3. **Форма заказчика.** Нажмите «Файл формы…» и выберите заполненный документ заказчика (.docx или .xlsx). Поставьте курсор на акт, по которому он заполнен, и напишите «Сделай форму по этому файлу». Программа расставит метки, где узнала значения. Помощник выберет варианты для спорных мест и предложит метки там, где программа значение не узнала. После «Применить» — «Скачать для проверки» и «Сохранить как форму»: выберите документ шаблона. Если книга пустая или акта из файла в ней нет, напишите «Заполни книгу по этому файлу»: помощник прочитает документ и предложит перенести объект, организации, представителей, шифр, акт и материалы; после «Применить» попросите сделать форму по новому акту. Для встроенного шаблона будет создана копия, и её выберут для книги.
4. **Бланки и формы документов.** Помощник меняет вид документов шаблона книги: «Для шаблона Камчатка убери из кабельного журнала строку с запасом и столбцы лоток, труба гладкая, труба гофрированная», «в РИМ переименуй „Кол-во листов“ в „Листов“», «печатай КЖ по форме СБД», «запас кабеля 5 %». В карточке будет одно предложение «Шаблон «…», бланк «…»: без графы …». После «Применить» документы всех актов печатаются по-новому (PDF и Excel); «Отменить применённое» возвращает прежний вид. Если книга на встроенном шаблоне («СБД», «ТИ»), будет создана его копия с изменением и выбрана для книги. Данные книги при этом не меняются. Своя форма заказчика (файл Word/Excel) меняется только в самом файле: «Шаблоны» → «Скачать форму», правка, «Загрузить форму».
5. Помощник знает устройство книги и сам ищет нужное: «проверь 3 раздел ОЖР» (сверка журнала с актами), «где встречается Беляцкий», «поменяй Беляцкого на Антрохина» (одна замена во всех ячейках). Подписи в актах берутся из «Представителей» по роли и периоду, а на отдельном акте — из его столбца «Подписанты» («поставь Заменова подписантом в акте 12»).
6. «Новый разговор» начинает разговор заново.
7. **Роли** (0.34) — кнопки над полем ввода:
    - **«Проверка как технадзор»** — строгая проверка, как при приёмке ИД: п.1–7 акта, документы качества на даты работ, схемы, даты, подписанты и их полномочия, ВОР, приложения. Рядом выбор: акт под курсором или все акты книги. Ответ — замечания по актам («что исправить, где»), сначала критичные, в конце итог: сколько актов можно сдавать. Однозначные исправления помощник сразу предлагает карточкой.
    - **«Черновики актов из РД…»** — выберите файл рабочей документации: PDF (с текстом, не скан; читаются первые 40 страниц), Word или Excel. Помощник предложит шифр, акты скрытых работ по видам работ (п.1 конкретно, нормативы п.6, п.7 — следующие работы, вид работ из справочника) и материалы из спецификации с привязкой к актам. Даты, представителей, документы качества и схемы допишите сами — помощник их не придумывает.

Лучше всего помощник работает на сильной модели: для YandexGPT — Pro (поле «Модель» пустое — берётся `yandexgpt/latest`), не Lite.

**Ответ по мере генерации.** Текст ответа появляется в чате сразу, по мере того как нейросеть его пишет. Пока ответ идёт, кнопка «Отправить» неактивна, а рядом есть **«Остановить»**: она прерывает ответ, полученная часть остаётся в чате с пометкой «остановлено», и помощник учитывает её в следующем вопросе. Если связь оборвалась посреди ответа, полученная часть тоже остаётся — с пометкой «ответ прерван». У GigaChat ответ приходит целиком.

**Сбои связи.** Если нейросеть не ответила из-за сбоя сети или перегрузки сервиса, программа сама повторяет запрос (до трёх попыток; при ограничении частоты запросов — после паузы, которую назвал сервис). Ошибка в чате появляется, только если все попытки не удались, — в ней указано подключение и число попыток. Разговор можно продолжить новым вопросом.

Помощник может ошибаться: проверяйте предложения перед применением. Если подключение не отвечает — «Проверить» в настройках покажет причину.

## Мастер первого акта

В книге без актов панель предлагает **«Мастер первого акта»** (кнопка есть и на листе «База актов»). Пять шагов:

1. **Объект** — наименование, адрес, город.
2. **Участники** — организации по ролям АОСР (застройщик, лицо, осуществляющее строительство, проектировщик и, если работы выполнила другая организация, она) и их представители. Начните вводить наименование или ФИО — программа подставит данные из библиотеки компании.
3. **Шифр раздела** проекта.
4. **Материалы** акта и их количество.
5. **Акт** — номер, дата, работы (п.1), начало и окончание работ, нормативы (п.6), разрешаемые работы (п.7).

«Далее» не пускает дальше, пока у поля написано «Заполните». «Создать акт» записывает всё на обычные листы книги (то, что уже есть, не дублируется), затем — «Печать АОСР». Дальше книга ведётся как обычно: схемы, ВОР, документы качества добавляются на своих листах.

## Только нужные листы

Программа показывает только листы, нужные документам шаблона книги (галочка **«Только нужные листы»** в «Функционале листа» включена сразу). Всегда видны основные листы: «Реквизиты», «Представители», «Материалы» (материалы, позиции РКЦ и документы качества), «База актов», «Материалы в актах», «Комплекты», «Реестр ИД». Остальные — по документам шаблона: например, «ВОР» — только если в шаблоне есть ВОР, «Кабельный журнал» и «Изоляция» — если есть КЖ или протокол изоляции, листы замеров — если есть их протоколы. Листы ОЖР появляются, когда в них есть данные. Строки-примеры новой книги лист не держат. Убрали или добавили документ в шаблоне — листы пересчитываются сами. Снимите галочку — снова видны все листы.

## Библиотека компании

Организации, представители, материалы и документы качества со сканами повторяются от объекта к объекту. Библиотека хранит их один раз на компанию.

1. **Пополнить.** На листе «Реквизиты», «Представители» или «Материалы» (справочник или документы качества) выделите строки → в «Функционале таблицы» — **«В библиотеку»**. Документ качества сохраняется вместе со сканом. Повторное сохранение той же записи обновляет её (организация — по ИНН, представитель — по ФИО и организации, материал — по наименованию и марке, документ — по виду и номеру).
2. **Взять в книгу.** Верхняя строка → **«Библиотека»** → раздел, поиск, отметьте записи → **«Добавить в книгу»**. Материал приходит вместе со своими документами качества и сканами, представитель — со своей организацией. То, что уже есть в книге, не дублируется.
3. **Общая библиотека.** «Настройки» → «Папка библиотеки компании»: укажите общую сетевую папку (например, `\\server\ИД\Библиотека`) на каждом компьютере — тогда у всех инженеров одна библиотека. Пусто — библиотека на этом компьютере. Если сеть недоступна, программа так и скажет, а книга работает как обычно.

## Настройки и шаблоны

Вверху «Настроек» — **«Версия программы»**: установленная версия. Если Excel показывает панель прежней версии (после обновления), там же будет предупреждение: закройте Excel полностью и откройте снова; если не поможет — закройте Excel и очистите папку `%LOCALAPPDATA%\Microsoft\Office\16.0\Wef` (кэш надстроек).

- **Папка библиотеки компании** — «Настройки» (см. «Библиотека компании»).
- **⚙ ▾ (Ещё)** — шаблон книги («СБД», «ТИ» или свой), «Редактор шаблонов» и «Поля для шаблона» (см. «Свои шаблоны»). Выбор сохраняется в книге.
- **П.4 АОСР** — «Исполнительная схема» только перед первой схемой (как в образце СБД: «Исполнительная схема №1. …; №2. …») или перед каждой. Это настройка шаблона: «Редактор шаблонов», рядом с документом АОСР. У встроенного «СБД» — всегда перед первой; чтобы печатать перед каждой, сделайте копию шаблона.
- **Режим «В ячейку»** в «Нормативе» запоминается на компьютере пользователя, а не в книге.

## Если что-то не работает

Если программа ведёт себя странно, откройте «Настройки» → **«Сообщить о проблеме»**: опишите, что делали, и нажмите «Отправить разработчику». Отчёт сразу уйдёт разработчику (в Телеграм), копия «Отчёт <дата>.zip» сохранится в папке «Документы\Конструктор ИД — отчёты». Если отправить не удалось (нет интернета, Телеграм закрыт в сети компании), панель скажет причину — тогда перешлите этот файл. В отчёте нет данных книги (только сколько строк в таблицах) и ключей нейросетей; разговор с помощником прикладывается, если оставить галочку.

| Что видно | Что сделать |
| --- | --- |
| Установщик: «Не удалось добавить сервер в автозагрузку» (до 0.30.3) | Поставьте 0.30.3 и новее: если ярлык в «Автозагрузке» создать нельзя (политика компании, антивирус), запуск сервера прописывается в реестр пользователя; если нельзя и это — установка завершится с подсказкой запускать сервер через «Пуск» → «Конструктор ИД» → «Перезапустить сервер». |
| Нет кнопки «Конструктор ИД» в Excel | Закройте все окна Excel и откройте снова. Не помогло — запустите установщик ещё раз. |
| Две кнопки «Конструктор ИД» | Осталось старое подключение через общую папку: удалите каталог в «Файл» → «Параметры» → «Центр управления безопасностью» → «Доверенные каталоги надстроек». |
| Панель пустая или «Не удалось открыть страницу» | Не запущен сервер или не установлен сертификат. «Пуск» → «Конструктор ИД» → «Перезапустить сервер»; не помогло — запустите установщик и ответьте «Да» на вопрос о сертификате. |
| «Сервер не запущен» на панели | «Пуск» → «Конструктор ИД» → «Перезапустить сервер». Причину покажет журнал `server.log` в «Папке данных». |
| «В книге нет таблиц…» или «Книга размечена прежней версией» | Нажмите «Обновить разметку» — данные не изменятся. |
| При печати — список ошибок | Щёлкните по строке списка — курсор перейдёт к ячейке; заполните и повторите печать. |
| «Не найден браузер для печати» | Печать идёт через Microsoft Edge — установите его или перезапустите сервер. |
| Окно предпросмотра пустое | «Открыть в браузере» или «Скачать PDF» вверху окна. |
| «Нет связи с порталом protect.gost.ru» | Проверьте интернет и повторите «Обновить базу» позже. |

### Данные и резервные копии

Главное — книга объекта: храните и копируйте её как обычный файл. Сервер раз в день делает резервную копию своих данных (прикреплённые сканы, справочник) в папку `backups` внутри «Папки данных». Сканы из «Папки сканов» объекта программа не копирует — храните их вместе с книгой.
