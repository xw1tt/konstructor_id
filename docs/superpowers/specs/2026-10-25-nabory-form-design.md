# Наборы форм: встроенные варианты документов и набор «ТИ»

Дата: 25.10.2026. Статус: согласовано с пользователем 25.10.2026 («начинай»).

## 1. Цель

Пользователь должен менять форму документа, не размечая её сам: выбрать из встроенных вариантов. Первый
дополнительный набор — «ТИ» по образцам пользователя (ООО «Техноинжиниринг», объект «Аэропорт Оренбург»): ВД, реестр
применённых материалов (РМ), реестр приложений к АОСР (РП, новый документ), кабельный журнал, реестр ИД. АОСР и протоколы —
встроенные, с нумерацией набора. Новые варианты добавляются в программу по присланным образцам.

Решения пользователя: КЖ — новые столбцы книги; нумерация — часть набора; РП — новый документ; АОСР — встроенный по 344/пр.

### Критерии успеха

1. Шаблон «ТИ» (встроенный, только чтение, как «СБД») печатает АОСР, РМ, РП, ВД, КЖ, протокол с номерами набора и
   собирает комплект с реестром в вёрстке «ТИ».
2. В своём шаблоне можно выбрать набор (нумерацию) и для ВД, РИМ, КЖ и реестра — форму «СБД» или «ТИ».
3. Встроенные шаблоны не прячут выбор форм: изменение у «СБД»/«ТИ» создаёт копию шаблона с этим изменением.
4. Книга v9 → «Обновить разметку» → новые столбцы КЖ и вид реестра «РП»; прежние книги и шаблоны печатаются как раньше.

## 2. Модель

`PrintOptions` (хранится в `UserTemplate.print`, уходит с каждым заданием печати и комплекта) дополняется:

| Поле | Тип | По умолчанию | Смысл |
|---|---|---|---|
| `formSet` | `"sbd" \| "ti"` | `"sbd"` | нумерация и формы по умолчанию |
| `forms` | `Partial<Record<"vd" \| "rim" \| "kj" \| "registry", "sbd" \| "ti">>` | `{}` | форма документа вопреки набору |
| `kjReserve` | число, % | 2 | коэффициент запаса в КЖ «ТИ» |

`formOf(options, doc)` = `options.forms[doc] ?? options.formSet`.

### 2.1. Нумерация (`docNumberFor(base, kind, set)`)

| Документ | СБД | ТИ |
|---|---|---|
| АОСР | `base.АОСР` | `base` |
| РИМ/РМ | `base.РИМ` | `base.РМ` |
| РП | `base.РП` | `base.РП` |
| ВД | `base.ВД` | `base.ВД` |
| КЖ | «Шифр журнала» | `base.КЖ` |
| Протокол изоляции | «№ протокола» | `base.П` |
| Реестр ИД | `РЕЕСТР … №<комплект>.<шифр>` | `Реестр №<комплект>/<шифр>.Р` |

В наборе «ТИ» «Шифр журнала» и «№ протокола» в «ДокументыКабелей» не обязательны. Нумерация применяется в печати,
реестре ИД, п.3 АОСР и метках своих форм. ОЖР — как раньше (вне рамок).

### 2.2. Новый документ РП

Вид печати `rp`, подпись «РП», вид строки реестра «РП» (после «РИМ»). Строки — документы качества материалов акта в
порядке РИМ: тип, дата, номер, листов. Наименование в реестре: «Реестр приложений к АОСР №<АОСР> от <дата>».

### 2.3. Книга v10

«КабельныйЖурнал» — в конце: `projectLength` «Длина по проекту, м», `tray` «Лоток, м», `smoothPipe` «Труба гладкая, м»,
`corrugatedPipe` «Труба гофрированная, м» (числа). Фактическая длина в КЖ «ТИ» = сумма трёх; все пусты — «Кабель: длина».

### 2.4. Встроенный шаблон «ТИ»

id `ti`, имя «ТИ», документы: АОСР, РИМ, РП, ВД, КЖ, протокол; `print = {formSet:"ti"}`. Список шаблонов сервера:
«СБД», «ТИ», затем свои.

## 3. Формы «ТИ» (по образцам)

- **Шапка ВД и КЖ:** подрядчик (выполнивший работы акта) «(подрядная организация)» | город «(город)»; наименование и
  шифр раздела «(участок)» | заказчик «(заказчик)»; объект «(объект)»; дата «"15" октября 2026г.».
- **ВД** (книжный): «ВЕДОМОСТЬ № <номер>» / «СМОНТИРОВАННОГО ЭЛЕКТРООБОРУДОВАНИЯ И МАТЕРИАЛОВ»; графы «№ п/п, Наименование
  электрооборудования, комплекта, Тип, марка (марка, иначе артикул), Кол-во, Ед. изм., Примечания», номера граф; подписи
  пяти ролей АОСР: подпись роли, ФИО, «(фамилия, инициалы, подпись)».
- **РМ** (книжный): «РЕЕСТР / применённых материалов / №<номер>», «к АОСР <номер АОСР> от <дата>г.»; графы «№,
  Наименование, Дата документа, Номер документа»; строка документа (серая): тип | дата | номер; под ней его материалы
  акта с номерами 1, 2, …; подписи как у ВД.
- **РП** (книжный): «РЕЕСТР / документов, подтверждающих соответствие работ / №<номер>», «к АОСР <номер> от <дата>г.»;
  графы «№, Наименование, Дата документа, Номер документа, Лист»; подписи как у ВД.
- **КЖ** (альбомный): шапка, «Кабельный журнал №<номер>»; графы «Обозначение кабеля, провода | Трасса: Начало, Конец |
  Кабель: Марка, Длина по проекту, м, Длина фактическая, м | Способ прокладки: Лоток, Труба гладкая, Труба гофрированная»;
  строки групп («2 этаж, отм. +5.400»); «Итого всего» (по способам прокладки), «в т.ч. <марка>» (проект, факт), «с учетом
  кф запаса N%» (факт и способы × (1 + N/100), вверх до целого); пустая длина по проекту — «-»; «Сдал: … Подпись … Дата»,
  «Принял: …». Шапка таблицы повторяется на страницах.
- **Реестр ИД** (книжный): «Заказчик: …», «Подрядчик: …», объект «(объект)», шифр «(шифр проекта)», раздел «(участок)»;
  «Реестр №<комплект>/<шифр>.Р» / «Исполнительной документации»; графы «№п/п, Наименование документа, № документа, Дата
  документа, Кол-во листов, Страницы по списку» (без «л.»); «Сдал:» / «Принял:» с «(Ф.И.О.) (подпись) (дата)».
- **Строки реестра в наборе «ТИ»:** АОСР — «Акт освидетельствования скрытых работ»; РМ — «Реестр используемых материалов и
  документов, подтверждающих их качество, к АОСР №… от …г.»; РП — §2.2; ВД — «Ведомость смонтированного
  электрооборудования и материалов»; КЖ — «Кабельный журнал»; протокол — «Протокол сопротивления изоляции»; документ
  качества — тип («Сертификат соответствия»), номер без «№».

## 4. Редактор шаблонов

У шаблона — «Набор форм и нумерация» (СБД / ТИ), у ВД, РИМ, КЖ — «Форма: СБД / ТИ», у шаблона — «Реестр ИД: СБД / ТИ», у
КЖ при форме «ТИ» — «Запас, %». У встроенного шаблона те же элементы активны: изменение создаёт копию «<имя> (копия)» с
этим изменением и открывает её. «Добавить встроенный» предлагает и РП.

## 5. Метки своих форм

Новые поля: «Акт.День», «Акт.Месяц» (родительный падеж), «Акт.Год», «Объект.Подрядчик», «Акт.Номер РП»; номера
«Акт.Номер АОСР/РИМ/ВД» — по набору шаблона.

## 6. Тесты

Нумерация обоих наборов; схема v10 и обновление разметки; КЖ «ТИ»: факт = сумма, пусто — длина, итоги и запас (округление
вверх); РМ: группы документ → материалы; РП и ВД: строки, подписи; реестр «ТИ»: наименования и номера строк; HTML и PDF
каждой формы «ТИ»; комплект с реестром «ТИ»; шаблон «ТИ» в списке; прежние тесты «СБД» без изменений.
