# Конструктор ИД

Надстройка Excel для сборки исполнительной документации. Состоит из локального
сервера (хранит базу и файлы) и панели в Excel.

Версия 0.1 (план 1): вкладки «Объект» и «Материалы».

## Установка на Windows

1. Установите **Node.js 22 LTS** (версия 22.13 или новее) с сайта nodejs.org
   (установщик по умолчанию).
2. Откройте командную строку в папке проекта и выполните:
   ```
   npm install
   npm run build
   ```
3. Запустите сервер:
   ```
   scripts\start.cmd
   ```
   В окне появится строка `Конструктор ИД: https://localhost:3443/addin/`.
   При первом запуске сервер создаёт папку данных
   `%LOCALAPPDATA%\KonstruktorID` (база, сканы, резервные копии, сертификаты).
4. Разрешите Windows доверять сертификату сервера. В PowerShell из папки проекта:
   ```
   powershell -ExecutionPolicy Bypass -File scripts\install-cert.ps1
   ```
   Windows спросит подтверждение — ответьте «Да». Этот корневой сертификат
   ограничен именами `localhost` и `127.0.0.1` и не годится для других сайтов.
5. Проверьте: откройте в браузере `https://localhost:3443/addin/index.html` —
   должна открыться панель без предупреждения о сертификате.

## Подключение надстройки к Excel

Excel загружает надстройки из «общей папки каталога». Её нужно один раз
настроить.

1. Создайте папку, например `C:\Addins`, и скопируйте в неё файл
   `packages\addin\dist\manifest.xml` (появляется после `npm run build`).
2. Откройте общий доступ к папке: правый щелчок по папке → «Свойства» →
   «Доступ» → «Общий доступ…» → «Поделиться». Запомните сетевой путь,
   например `\\ИМЯ-КОМПЬЮТЕРА\Addins`.
3. В Excel: «Файл» → «Параметры» → «Центр управления безопасностью» →
   «Параметры центра управления безопасностью» → «Доверенные каталоги
   надстроек». Вставьте сетевой путь в «URL-адрес каталога», нажмите
   «Добавить каталог», отметьте «Показывать в меню», нажмите «ОК».
4. Перезапустите Excel.
5. «Вставка» → «Мои надстройки» → вкладка «Общая папка» → «Конструктор ИД» →
   «Добавить». На вкладке «Главная» появится кнопка «Конструктор ИД».

## Автозапуск сервера

Чтобы сервер запускался вместе с Windows:
```
powershell -ExecutionPolicy Bypass -File scripts\register-autostart.ps1
```

## Данные и резервные копии

- Папка данных: `%LOCALAPPDATA%\KonstruktorID` (другую можно задать переменной
  окружения `IDK_DATA_DIR`).
- При каждом запуске сервер раз в сутки делает копию базы и сканов в
  `backups\ГГГГ-ММ-ДД` и хранит 30 последних копий.
- Чтобы восстановить данные:
  1. Остановите сервер (закройте его окно).
  2. В папке данных удалите файлы `db.sqlite-wal` и `db.sqlite-shm`, если они есть.
     Иначе SQLite применит к восстановленной базе изменения из старого журнала.
  3. Скопируйте `db.sqlite` и папку `files` из нужной копии в папку данных.

## Если что-то не работает

- **В панели «Сервер не запущен».** Запустите `scripts\start.cmd` и нажмите
  «Повторить».
- **«Порт 3443 занят: сервер уже запущен?»** Сервер уже работает в другом окне —
  второй запускать не нужно.
- **Панель пустая или предупреждение о сертификате.** Повторите шаг 4 установки
  и перезапустите Excel.
