# Дополнение к спецификации: формы СБД (АОСР, РИМ, ВД, ВОР)

Дата: 16.10.2026
Основание: комплект «Монтаж кабеля» (АОВ1.01.00.1, ООО «СБД»). По словам пользователя,
формы в присланных документах — самые актуальные.
Дополняет `2026-10-15-konstruktor-id-design.md` (разделы 5.2 и 6) и уточняет его.

## 1. Нумерация документов комплекта

- У акта есть **базовый номер**, например `К32.В.СТ.АОВ1.01.00.1`.
- Номера документов получаются добавлением суффикса:
  - АОСР — `<база>.АОСР`;
  - РИМ — `<база>.РИМ`;
  - ВД — `<база>.ВД`.
- Номера исполнительных схем пользователь вводит сам (`К32.В.СТ.АОВ1.01.00.1`, `…00.2` и т. д.).
- В документах номер печатается со знаком «№»: `№К32.В.СТ.АОВ1.01.00.1.АОСР`.

## 2. АОСР

**Шапка.** Строки «Объект капитального строительства», «Застройщик…», «Лицо, осуществляющее
строительство…», «Лицо, осуществляющее подготовку проектной документации» заполняются полной
формой реквизитов организации.

**Номер и дата.** Дата печатается прописью месяца: `28 июля 2026 г.`

**Представители.** Строки строятся по роли:

| Роль | Формат строки |
|---|---|
| developer_control, builder_control | `<должность> <краткое имя орг.> <ФИО>, идентификационный номер специалиста №<НРС>, <документ о полномочиях>` |
| builder | `<должность> <краткое имя орг.> <ФИО>, <документ о полномочиях>` (НРС — если указан, как выше) |
| designer, performer, other | `<должность> <ФИО>, <документ о полномочиях>, <краткое имя орг.> ОГРН <…>, ИНН <…>, <адрес>` |

- Если у представителя заполнено поле **«Текст для акта»**, печатается оно вместо
  автоматической строки.
- В одной роли может быть несколько человек: каждый печатается своим абзацем.

**«Произвели осмотр работ, выполненных:»** — краткое имя организации, выполнившей работы.

**Пункты акта.**
- **П.1:** текст работ.
- **П.2:** `Шифр рабочей документации: <шифр> листы <листы>, <ревизия>, <краткое имя проектировщика>`.
- **П.3:**
  - если материалов ≤ 5 — по строке на материал: `<наименование> — <документы качества через «; »>`;
  - если больше 5 — `Согласно реестру использованных материалов №<база>.РИМ ведомости смонтированного оборудования, технических средств и материалов №<база>.ВД`.
- **П.4:** строки документов акта, у схем — `Исполнительная схема №<номер>. <наименование>`.
  **Для СБД все документы перечисляются в самом акте, отдельный реестр приложений не нужен.**
- **П.5:** даты начала и окончания прописью месяца.
- **П.6, п.7:** текст.
- **Дополнительные сведения:** по умолчанию «нет».
- **Число экземпляров:** по умолчанию 4.
- **Приложения:** по умолчанию «Согласно п.3, п.4.».

**Подписи.** Пять ролей в порядке: developer_control, builder, builder_control, designer,
performer. Под каждым именем — «(фамилия, инициалы, подпись)».

## 3. РИМ — «Приложение №2»

**Шапка.**
- «Приложение №2»;
- «Приложение к акту освидетельствования скрытых работ №<база>.АОСР»;
- заголовок «Реестр использованных материалов №<база>.РИМ»;
- подзаголовок «Сопроводительные документы качества (паспорта, сертификаты, заключения и т.д.)».

**Таблица:** № п/п | Наименование материалов | Тип документа | Номер документа | Дата документа | Кол-во листов.

**Правила строк.**
- Одна строка — один документ качества. Документ, относящийся к нескольким материалам акта,
  печатается **один раз**.
- Порядок строк:
  1. по порядку материалов в акте;
  2. внутри материала по типу документа: паспорт, сертификат, декларация,
     информационное письмо, отказное письмо, прочее.
- **Наименование:**
  - поле документа «Наименование для реестра», если оно заполнено;
  - иначе наименования материалов акта, к которым относится документ, через «, ».
- **Тип:** подпись типа строчными буквами («паспорт качества»).
- **Номер:** со знаком «№».
- **Дата:**
  - есть срок действия — `от ДД.ММ.ГГГГ г. до ДД.ММ.ГГГГ г.`;
  - нет срока — `ДД.ММ.ГГГГ г.`

**Подписи:** developer_control, builder, builder_control, performer (без проектировщика).

## 4. ВД — «Приложение №1»

**Шапка.**
- «Приложение №1»;
- «Приложение к акту…»;
- заголовок «Ведомость смонтированного оборудования, технических средств и материалов №<база>.ВД».

**Таблица:** № п/п | № поз по УСР | Наименование оборудования, комплекта | Артикул | Завод изготовитель | Ед. изм. | Кол-во.

**Источники колонок.**

| Колонка | Источник |
|---|---|
| № поз по УСР | строка материала в акте, по умолчанию «б/н» |
| Наименование, артикул, завод, ед. изм. | общая таблица материалов. Если артикул пуст, берётся марка |
| Кол-во | строка материала в акте |

**Количество в ВД.**
- Если у материала есть строки ВОР, программа подставляет их сумму.
- Его можно изменить вручную.

**Числа:** десятичная запятая (1618,9).

**Подписи:** как у РИМ.

## 5. ВОР — ведомость объёмов выполненных работ

**Шапка.**
- «Объект:» и наименование объекта;
- заголовок «Ведомость объёмов выполненных работ»;
- строка «Комплекс работ…» — поле акта, по умолчанию наименование раздела;
- «Объём работ составлен согласно комплектам исполнительной документации: № <шифр>».

**Таблица:** № | Наименование работ | Ед. изм. | Объем | Примечания.

**Группы.**
- Строки сгруппированы по этажам или участкам.
- Заголовок группы — отдельная пронумерованная строка, жирным по центру.

**Строка материала.**
- Наименование: `<наименование> (<артикул или марка>, <завод>)`.
- Единица измерения — из общей таблицы.
- Объём — из строки ВОР.

**Подписи.** Две строки:
- «Представитель заказчика: <должность> <орг.> <ФИО>»;
- «Представитель монтажной организации: <должность> <орг.> <ФИО>».

Обоих подписантов выбирает пользователь в акте. По умолчанию — первый представитель роли
developer_control и последний представитель роли performer.

**Колонтитул:** «Страница N из M».

## 6. Печать

- **Шрифт:** Times New Roman (в среде разработки — метрически совместимый Liberation Serif).
- **Формат:** A4, книжная ориентация, поля как в образце.
- **Движок печати:**
  - на Windows используется установленный **Microsoft Edge** (через playwright-core,
    канал `msedge`), скачивать браузер не нужно;
  - путь к другому браузеру можно задать переменной `IDK_BROWSER`.
- **Не печатается** то, чего нет в комплекте СБД:
  - отдельный «реестр приложений к АОСР»;
  - блоки «иные представители», если в роли `other` никого нет.
