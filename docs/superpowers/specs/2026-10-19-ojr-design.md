# Общий журнал работ (приказ Минстроя России от 02.12.2022 № 1026/пр): разделы 3 и 5

## Решения
| Вопрос | Решение |
|---|---|
| Где журнал | Листы книги «ОЖР Раздел 3», «ОЖР Раздел 5»: «Заполнить из актов», правка, печать PDF |
| Графа 3 «Условия производства работ» | Поле «Объекта» «Условия производства работ» — в каждую строку; правка в строке сохраняется при повторном заполнении (по дате) |
| Графа 5 раздела 3 | Подписант ВОР от монтажников акта, иначе последний по «Порядку» выполнивший работы; разные — каждый с новой строки |
| Раздел 5 | АОСР с приложениями, исполнительные схемы, АВК, КЖ, протокол изоляции |
| Печать | Только разделы 3 и 5 по форме приказа, А4 книжный, «Страница N из M» |

## Раздел 3 («Сведения о выполнении работ…»), таблица `ОЖР3`
Столбцы: «Дата» (дата), «Условия производства работ», «Наименование выполненных работ» (длинный текст),
«Представитель» (должность, фамилия, инициалы), «Акты» (служебный: номера актов строки).
Заполнение: акты книги с «Началом» и «Окончанием» работ по порядку «Базы актов»; каждая дата периода, кроме
воскресенья, — работы п.1 акта; одна строка на дату (даты по возрастанию), работы дня — по порядку актов,
каждая с новой строки (повтор текста работ в один день — один раз). № п/п — порядковый номер строки при печати.

## Раздел 5 («Перечень исполнительной документации…»), таблица `ОЖР5`
Столбцы: «Наименование исполнительной документации», «Дата подписания и подписавшие», «Акт» (служебный).
По каждому акту:
- «Акт освидетельствования скрытых работ №<…>.АОСР <работы п.1>[, приложения: реестр использованных материалов
  №<…>.РИМ, ведомость смонтированного оборудования №<…>.ВД]» — дата акта; все подписанты АОСР (должность ФИО);
- «Исполнительная схема №<…> <наименование>» (вид «Прочее» — как есть) — дата схемы; выполнившие работы и
  строительный контроль лица, осуществляющего строительство;
- «Акт входного контроля, технических средств и материалов №<…>» (если есть материалы) — дата АВК; представители
  заказчика и монтажной организации;
- «Кабельный журнал № <шифр>» (если есть кабели) — дата журнала; подписи штампа;
- «Протокол №<…> проверки сопротивления изоляции…» (если есть № протокола) — дата окончания измерений;
  руководитель электролаборатории и проводивший испытания.
Порядок: по дате подписания, в одну дату — по порядку актов и документов.
Графа 3: «28.07.2026 г. Ведущий инженер … Валерьянов А.А.; Заместитель … Аксенов А.М.; …».

## Печать
Кнопки «Раздел 3», «Раздел 5» в карточке строк ОЖР (и «Заполнить из актов»). Шапка: «Раздел 3. Сведения о выполнении
работ в процессе строительства, реконструкции, капитального ремонта объекта капитального строительства»,
таблица с графами формы и строкой номеров граф 1…5 (1…3), повтор шапки, «Страница N из M».
