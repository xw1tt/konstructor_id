# Сверка печатных форм с образцом СБД (план 2)

**Контрольный пример:** акт №К32.В.СТ.АОВ1.01.00.1 из комплекта «Монтаж кабеля.pdf».
Данные загружаются командой `npm run seed:sbd`.

**Сравнительные изображения** («образец | конструктор») лежат в `docs/screens/plan2-compare-*.png`.

## Итог по документам

| Документ | Страниц: образец / конструктор | Содержание | Отличия |
|---|---|---|---|
| АОСР | 2 / 2 | Совпадает: шапка с полными реквизитами, 6 представителей (двое в роли «выполнившего работы»), п.1–7, подписи | Шрифт в среде разработки — Liberation Serif (на Windows будет Times New Roman); переносы строк местами другие |
| РИМ (Приложение №2) | 2 / 2 | 24 строки, те же документы, типы, номера, даты («от … до …»), листы | Письмо №2022 (на один профиль L1000) стоит сразу после паспорта этого профиля (стр. 18), в образце — последней строкой. Порядок у нас по правилу, а не вручную |
| ВД (Приложение №1) | 1 / 1 | 20 строк, количества совпадают до десятых (кабель 1618,9 м) | Нет |
| ВОР | 3 / 2 | 98 строк: 4 этажа и раздел «Итого по этажам П5, П4, П3, П2», объёмы совпадают, подписи двух представителей | Строки у нас плотнее, поэтому 2 страницы вместо 3. Подписи не отрываются от таблицы |

## Что было исправлено по итогам сверки

- В реквизитах организаций добавлено «является членом **организации:** …», в конце полной
  формы стоит точка — как в бланке.
- В п.4 «Исполнительная схема» пишется только перед первой схемой, следующие перечисляются
  через «;».
- В п.6 после «в соответствии с» нет двоеточия.
- В РИМ документ, общий для нескольких материалов (письма №2448 и №176), стоит после
  документов последнего из этих материалов — как в образце.
- В ВОР добавлен итоговый раздел по этажам: в образце он есть, суммы совпадают с ВД.
- Вёрстка ужата под число страниц образца: АОСР — 2, РИМ — 2, ВД — 1.

## Что осталось не так, как в образце, и почему

- **Номер и дата акта.** В образце номер и дата набраны в одной строке с разной шириной
  полей. У нас поля той же ширины, текст идентичен.
- **Подписи-пояснения под линиями** (мелкий шрифт) взяты из формы приказа Минстроя 344/пр.
  В образце часть из них длиннее (включает формулировки для физических лиц). На содержание
  акта это не влияет.
- **Порядок строк РИМ, заданный вручную** (письмо №2022 в конце), правилом не воспроизводится.
  Если такой порядок важен, позже можно добавить ручную сортировку строк реестра.
