# Плагин AutoCAD «Конструктор ИД»

Заполняет лист исполнительной схемы данными из книги: **ведомость объемов работ** (таблица) и **основную надпись**.
Чертёж — подложку проекта и трассу — делает инженер, как и раньше.

Две сборки в одном bundle: AutoCAD 2016–2024 — `Contents/net46` (.NET Framework 4.6, API R20.1); AutoCAD 2025–2026 — `Contents/net8` (.NET 8, API R25.0). AutoCAD 2027 (.NET 10) — пока нет.

## Как работает

1. В книге, лист «Исполнительные схемы»: строка схемы (акт, номер, наименование «Монтаж … на отм. … в осях …»)
   и её ведомость в таблице «Ведомости схем» — только объём, изображённый на этом листе.
   В карточке схемы: «Заполнить из материалов акта» предлагает остаток акта за вычетом других схем.
2. Кнопка **«В AutoCAD»** в карточке схемы — данные листа уходят на сервер Конструктора ИД.
3. В AutoCAD на листе (вкладка листа с рамкой):
   - `IDKVED` (`ИДВЕДОМОСТЬ`) — указать левый верхний угол, вставится таблица «Ведомость объемов работ»;
   - `IDKSTAMP` (`ИДШТАМП`) — заполнит шифр, объект, раздел, «Исполнительная схема №…», стадию, организацию,
     «Разработал»/«Проверил». Найденный в графе текст заменяется с сохранением шрифта и цвета, пустая графа заполняется.

Рамка ищется как блок с надписью «Стадия» или «Формат» (как «ФорматкаОчищенная» в листах ИД);
графы — по форме 3 ГОСТ Р 21.101 от правого нижнего угла внутренней рамки, масштаб — по масштабу блока рамки.

## Установка

Папку `IdkAcad.bundle` скопировать в `%APPDATA%\Autodesk\ApplicationPlugins\` и перезапустить AutoCAD.
Разово, без установки: команда `NETLOAD` → `IdkAcad.bundle\Contents\net8\IdkAcad.dll` (AutoCAD 2025–2026) или `Contents\net46\IdkAcad.dll` (2016–2024).

Сервер — `https://localhost:3443` (другой порт: переменная окружения `IDK_PORT`, другой адрес — `IDK_URL`).

## Сборка и проверка

    dotnet build packages/acad -c Release        # bin/Release/net46 (AutoCAD.NET 20.1.0) и net8.0-windows (25.0.1)
    dotnet run --project packages/acad/test      # логика без AutoCAD: правка MTEXT, графы штампа, разбор задания
