# Верхняя строка панели, реестр «Норматив», выбор шаблона

Дата: 16.10.2026
Дополняет `2026-10-16-kniga-obekta-design.md`.

## 1. Цель

- Над панелью — строка навигации: ⌂ (конструктор), «Норматив», «Помощник», «Шаблоны ▾» и значки
  помощника справа.
- «Норматив» — реестр нормативных документов объекта. Программа **не хранит и не
  распространяет тексты нормативов**: документ открывается напрямую с официального портала
  protect.gost.ru; программа лишь показывает страницы, которые портал отдаёт для сеанса
  пользователя.
- «Помощник» и значки справа — заготовки без действия.
- «Шаблоны» — выбор формы документов (сейчас только СБД) на будущее.

## 2. Верхняя строка

```
[⌂] [Норматив] Помощник [▦ Шаблоны ▾]      🔍 ↻ 💬 🔔 ? ☰
```

| Элемент | Поведение |
|---|---|
| ⌂ | Экран «Конструктор ИД» (разделы, функционал листа и таблицы, карточка — как в версии 0.3) |
| Норматив | Экран реестра (§3). Активный экран выделен тёмной «таблеткой» с белым текстом |
| Помощник | Текст с цветным градиентом; экран-заготовка «Помощник появится в следующих версиях» |
| Шаблоны ▾ | Список: «СБД» (отмечен), неактивная строка «Другие заказчики — позже». Выбор хранится в настройке документа `idk.template` (по умолчанию `sbd`) |
| 🔍 ↻ 💬 🔔 ? ☰ | Неактивные кнопки, подсказка «Скоро»; на колокольчике счётчика нет |

**Шаблон и печать.** Код шаблона передаётся на сервер вместе с пакетом акта (поле
`template`, по умолчанию `"sbd"`). Сервер принимает только известные коды (сейчас `sbd`),
иначе — 400 «Неизвестный шаблон: …». Шаблоны печати не меняются.

## 3. Реестр «Норматив»

### 3.1. Лист «Нормативы» — таблица `Нормативы`

| Столбец | Тип | Примечание |
|---|---|---|
| Обозначение | текст, ключ, важный | «СП 76.13330.2016» |
| Наименование | текст | |
| Вид | список: ГОСТ, ГОСТ Р, СП, ТР, ПУЭ, Прочее | важный |
| Статус | список: Действует, Заменён, Отменён | заполняет пользователь |
| Ссылка на портал | текст | необязательно; только `https://protect.gost.ru/…` |
| Примечание | текст | |

Лист создаётся «Созданием книги» / «Восстановлением разметки», как остальные. Раздел «Норматив»
— отдельный экран (не вкладка «Конструктора»); «Функционал листа» и «Функционал таблицы» на
листе «Нормативы» работают как везде.

### 3.2. Экран «Норматив»

- Строка поиска (по обозначению и наименованию, без учёта регистра) и список строк реестра:
  обозначение, наименование, статус.
- **«Открыть на портале»** у строки:
  - есть ссылка — открывается она;
  - нет — поиск портала по обозначению в разделе вида: ГОСТ и ГОСТ Р → `/gost`, СП → `/sp`,
    ТР → `/tr`; адрес `https://protect.gost.ru/<раздел>?search=<обозначение>`;
  - ПУЭ и «Прочее» без ссылки — кнопка неактивна, подсказка «Нет на портале».
- **«Собрать из актов»** — ищет обозначения в столбце «Нормативы (п.6)» всех актов и добавляет
  отсутствующие (сравнение без учёта пробелов и регистра) в конец таблицы с видом и статусом
  «Действует»; сообщает «Добавлено: N».
  Распознаются: `СП <цифры и точки>`, `ГОСТ Р <…>`, `ГОСТ <…>` (с годом через «-» или «.»),
  `ТР ТС <…>`, «ПУЭ».
- **«Вставить в п.6»** — активна, когда последняя выделенная строка была строкой листа «База
  актов»; добавляет `, <обозначение>` в конец п.6 этого акта (если обозначения там ещё нет;
  иначе сообщение «Уже есть в п.6»).
- Клик по строке списка выделяет её строку на листе.

### 3.3. Окно портала

- Открывается через Office Dialog API: окно загружает служебную страницу панели
  `/addin/portal.html?to=<адрес>`, которая сразу переходит на адрес портала (диалог Office
  требует, чтобы первая страница была с адреса панели).
- Служебная страница и панель разрешают только адреса, начинающиеся с
  `https://protect.gost.ru/`; иначе — «Можно открывать только страницы protect.gost.ru».
- Не удалось открыть окно — страница открывается в браузере по умолчанию.
- Программа не загружает страницы портала сама и ничего из них не сохраняет; вход на портал
  пользователь выполняет в окне.

## 4. Устройство кода

- `@idk/shared/normativ.ts`: `extractNormativ(text): { designation; kind }[]`,
  `portalUrl(row): string | null`, `isPortalUrl(url): boolean`, `normKey(designation)`.
- Схема книги: таблица `Нормативы` и лист «Нормативы» в `schema.ts`.
- Панель: `TopBar`, экраны `HomeScreen` (нынешняя панель), `NormativScreen`, `AssistantScreen`;
  `portal.html` + `portal.ts`; выбор шаблона — `templates.ts` (`TEMPLATES`, загрузка/сохранение).
- Сервер: поле `template` в пакете печати.

## 5. Проверка

- Автотесты: извлечение обозначений (в т.ч. из п.6 акта АОВ1 — СП 76.13330.2016, ПУЭ,
  СП 77.13330.2016, СП 134.13330.2012), адрес портала по виду, отказ для чужих адресов,
  «Собрать из актов» без повторов, «Вставить в п.6», шаблон по умолчанию и сохранение,
  400 на неизвестный шаблон.
- Вручную в Excel: окно портала открывается; фильтрует ли портал по `?search=` — проверяется
  на месте (если нет, открывается список раздела).

## 6. Вне рамок

Автоматическая проверка статуса нормативов на портале, загрузка текстов, работа помощника,
формы других заказчиков.
