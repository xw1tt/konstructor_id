# План 30: материалы на одном листе, материалы акта и документы качества — из карточек панели

**Запрос:** три листа о материалах («Материалы», «Документы качества», «Материалы в актах») — постоянно переключаться.
Решение пользователя: один лист «Материалы» (справочник и документы рядом), материалы акта — в карточке акта; документы
качества — кнопкой в карточке материала.

- [x] Схема: `SheetDef.side` (таблицы рядом), `panelOnly` («Материалы в актах» — служебный, скрыт); разметка 12.
- [x] ExcelPort: вторая таблица — справа от первой; вставка/удаление строк — только в столбцах таблицы; правила
  условного форматирования — со сдвигом столбца; перенос таблицы прежней версии на новый лист через временное имя
  (данные и ссылки на сканы; свои столбцы — старая таблица остаётся). Тесты на модели Excel `addin/test/helpers/fakeExcel.ts`.
- [x] `shared/acts/actMaterials.ts`: правки «Материалов в актах» по выбору, документ качества, привязка/отвязка.
- [x] Панель: «Материалы акта ▾» в карточке акта; «Новый документ…», «Привязать имеющийся», «Отвязать» в карточке
  материала; ошибки — «Материалы (документы качества), строка N».
