# Справочник нормативов портала; строки-примеры и подсказки в таблицах

Дата: 17.10.2026
Заменяет §3 спецификации `2026-10-16-normativ-shapka-design.md` (реестр «Норматив» на листе книги).
Верхняя строка, «Помощник», «Шаблоны» и окно портала (§2, §3.3 той спецификации) остаются.

## 1. Цель

1. Экран «Норматив» — **справочник всех нормативов портала protect.gost.ru** (≈5000 документов
   шести разделов) с поиском, фильтром по разделам, статусами и страницами. Программа хранит
   только сведения из списков портала (обозначение, наименование, страницы, статус, ссылка на
   карточку); **тексты нормативов не скачиваются и не хранятся**, документ открывается на портале.
2. В новой книге объекта у каждой таблицы — **строка-пример** и **подсказки** к каждому столбцу,
   чтобы было понятно, что вносить в каждую ячейку.

## 2. Справочник нормативов

### 2.1. Разделы портала

| Кнопка | Раздел | Адрес списка |
|---|---|---|
| СП | Своды правил | `https://protect.gost.ru/sp` |
| ГОСТ | ГОСТ, ГОСТ Р, ПНСТ | `https://protect.gost.ru/gost` |
| Правила | ПР, Р, ПМГ, РМГ | `https://protect.gost.ru/rst` |
| Классиф. | Классификаторы | `https://protect.gost.ru/classificators` |
| Техрегл. | Технические регламенты | `https://protect.gost.ru/tr` |
| Основопол. | Перечень основополагающих стандартов | `https://protect.gost.ru/foundational` |

Страницы списка — `<адрес>?page=N` (N с 1), по 20 строк. Строка списка: ссылка
`/<раздел>/details/<UUID>` с текстом обозначения, наименование, «Стр.» (число), статус
(«Действует», «Заменен», …; у «Основополагающих» есть столбец «№», а записи ещё раз повторены
блоками под таблицей).

### 2.2. Хранение (сервер)

Таблица базы `norm_catalog`: `section` (код раздела), `designation`, `title`, `pages` (целое),
`status` (как на портале, «е»/«ё» не нормализуются при хранении), `url` (полный адрес карточки,
только `https://protect.gost.ru/`), `ord` (порядок в списке портала). Отдельно — дата и время
последнего успешного обновления каждого раздела.

### 2.3. Обновление базы

- `POST /api/norms/refresh` запускает обновление в фоне (если уже идёт — 409 «Обновление уже
  идёт»). `GET /api/norms/refresh` — состояние: `{ running, section, page, pages, error, finishedAt }`.
- Сервер обходит разделы по порядку таблицы §2.1; в разделе — страницы с 1, пока на странице
  есть строки и номер ≤ числа страниц, указанного порталом (или пока очередная страница не
  пустая, если число не найдено). Пауза между запросами 300 мс; таймаут запроса 20 с;
  заголовок `User-Agent: Konstruktor-ID (справочник нормативов)`.
- Строки раздела накапливаются в памяти и записываются **одной транзакцией** (раздел целиком
  заменяется) только после успешного обхода всех его страниц. Ошибка сети или разбора — раздел
  не меняется, обновление останавливается с сообщением:
  - нет связи: «Нет связи с порталом protect.gost.ru»;
  - не разобралось (страница без строк на первой странице раздела, или ответ не HTML): «Не
    удалось разобрать список раздела «<Кнопка>» — возможно, портал изменил вёрстку».
- Повторы внутри раздела (одна и та же ссылка карточки) отбрасываются.

### 2.4. Разбор страницы списка

Чистая функция `parseListPage(html, base) → { rows, totalPages }`:
- строки — элементы с ссылкой на `/<раздел>/details/<UUID>`; обозначение — текст ссылки;
  из ячеек той же строки таблицы (`<tr>`): число — страницы, текст из списка статусов портала —
  статус, самый длинный оставшийся текст — наименование; столбец «№» игнорируется;
- блоки-повторы вне `<tr>` не дают новых строк (дедупликация по ссылке);
- `totalPages` — из «Стр. N из M» или наибольшего номера в ссылках `?page=`/`&page=`;
- HTML-сущности декодируются, пробелы схлопываются.

### 2.5. Чтение

`GET /api/norms?section=&q=&offset=&limit=` → `{ total, counts: {<раздел>: n}, updated: {<раздел>: ISO},
items: [{ id, section, designation, title, pages, status, url }] }`.
- `q` — поиск без учёта регистра и «ё/е» по обозначению и наименованию; несколько слов — все
  должны встречаться;
- `counts` — по всем разделам с учётом `q`;
- сортировка — порядок портала; `limit` по умолчанию 100, максимум 500.

### 2.6. Экран «Норматив»

```
[🔍 Поиск по обозначению и названию            ]
(СП 758) (ГОСТ 3421) (Правила 634) (Классиф. 112) (Техрегл. 59) (Основопол. 34)
[Читать] [Карточка] [В ячейку] [Обновить базу] [⚙] [Условия]
                          4999 документов, обновлён 13.10.2026
СП 1.13130.2009 с Изм. 1  [Заменён]                          47 с.
Системы противопожарной защиты. Эвакуационные пути и выходы
…
```

- Кнопки разделов — фильтр (повторное нажатие снимает); число — найдено в разделе.
- Метки статуса: «Действует» — зелёная, «Заменён»/«Заменен» — жёлтая, прочие — серая.
- Список подгружается по 100 при прокрутке; выделенная строка подсвечена.
- **«Читать»** — окно Office на карточке документа на портале (там «Просмотр документа»; вход
  на портал пользователь выполняет сам). Через `openPortal` — только адреса protect.gost.ru.
- **«Карточка»** — сведения строки в панели (раздел, обозначение, наименование, статус,
  страницы, адрес) и кнопка «Открыть на портале».
- **«В ячейку»** — обозначение в выделенную ячейку Excel: пустая — вписывается; непустая —
  дописывается «, <обозначение>» перед завершающей точкой; если обозначение там уже есть —
  сообщение «Уже есть в ячейке» (правила `appendToP6`).
- **«Обновить базу»** — запуск §2.3, ход: «Обновляю: СП, страница 12 из 38»; по окончании
  список перечитывается.
- **⚙** — неактивна, подсказка «Скоро».
- **«Условия»** — текст: «Программа не хранит и не распространяет тексты нормативов. В справочнике —
  только сведения из открытых списков портала protect.gost.ru (обозначение, наименование, число
  страниц, статус). Документы открываются напрямую с портала; окно лишь показывает страницы,
  полученные порталом для вашей сессии.»
- Пустая база: «Справочник пуст — нажмите «Обновить базу». Понадобится доступ к интернету,
  обновление займёт несколько минут.»
- Сервер не запущен — обычное сообщение «Сервер не запущен…».

### 2.7. Что убирается

Таблица и лист «Нормативы» в схеме книги, «Собрать из актов», «Вставить в п.6 акта», сообщение
о новом листе «Нормативы». Лист, уже созданный версией 0.4, программа не трогает и не использует.
`extractNormativ`, `normKey`, `isPortalUrl`, `openPortal`, `appendToP6` остаются.

## 3. Строки-примеры и подсказки

### 3.1. Строка-пример

- Создаётся **только** кнопкой «Создать книгу объекта», если данные из базы не переносятся
  (пустая база или пользователь отказался от переноса). В «Восстановлении разметки» и при
  переносе примеров нет.
- Одна строка в каждой таблице (в «Объекте» — значения всех полей), правдоподобные данные в
  формате СБД. Примеры связаны между собой: пример-акт ссылается на пример-шифр, пример-материал
  и т. д.
- **Признак примера** — ключевое значение строки начинается с «Пример: »
  («Пример: ООО "Строймонтаж"», «Пример: Иванов И.И.»); в таблицах без ключа так начинается
  значение ссылки на пример (акт, материал). Правило программы: **строка, в которой есть ячейка,
  начинающаяся с «Пример:», — пример**; в «Объекте» поле со значением «Пример: …» считается пустым.
- Примеры **не участвуют** в работе программы: не читаются в книгу (`readBook`), не попадают в
  проверку, печать, поиск ссылок, сводки и умолчания новых строк. В выпадающих списках Excel
  они видны (ограничение Excel) — с пометкой «Пример:».
- Оформление: условное форматирование «серый курсив», если в строке есть ячейка «Пример:*»;
  стоит заменить значение с «Пример:» своим — строка сразу становится обычной и обычного вида.
- Карточка строки-примера: плашка «Это строка-пример: замените значения своими или удалите строку».

### 3.2. Подсказки

- У каждого столбца (и каждого поля «Объекта») — подсказка: что вносить и формат,
  ≤ 255 символов (`ColumnDef.hint`).
- В Excel — всплывающая подсказка проверки данных (заголовок — заголовок столбца, обрезанный до
  32 символов; текст — `hint`) на ячейках данных столбца; показывается при выделении ячейки.
- В карточке — серый текст под полем.

## 5. Проверка

- Разбор: образцы HTML по увиденной структуре (обычный раздел, «Основополагающие» с «№» и
  блоками-повторами, сущности `&quot;`, пустая страница).
- Обновление: подменённый `fetch` — обход страниц, «всё или ничего» при ошибке на середине,
  409 при повторном запуске, сообщения об ошибках.
- Поиск: регистр, «ё», несколько слов, счётчики по разделам.
- Примеры: `readBook` их не видит; пример-акт не печатается; изменённая строка-пример становится
  обычной; у всех столбцов есть `hint` ≤ 255 и пример; примеры связаны (проверка пакета
  примера-акта, если снять с него признак, проходит без висячих ссылок).
- Вручную: «Обновить базу» на настоящем портале; подсказки при выделении ячеек в Excel.
