# Конструктор ИД

Надстройка Excel для сборки исполнительной документации. Все данные объекта хранятся
в листах книги Excel («книга объекта»); локальный сервер хранит сканы и печатает PDF.

Версия 0.3: книга объекта (листы «Реквизиты», «Представители», «Материалы»,
«Документы качества», «База актов», «Исполнительные схемы», «Материалы в актах», «ВОР»,
«Кабельный журнал»), панель с функционалом листа и таблицы, карточкой строки и печатью
АОСР, РИМ, ВД и ВОР в PDF по формам ООО «СБД». Нужен Excel 2019, 2021 или Microsoft 365.

## Установка (для пользователя)

1. Запустите `Установить Конструктор ИД.exe` (`KonstruktorID-Setup-<версия>.exe`). Если Windows покажет
   «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (установщик пока
   без цифровой подписи).
2. «Установить?» → «Да». Когда Windows спросит про сертификат «Konstruktor ID Local CA» — «Да».
3. Закройте и снова откройте Excel: на вкладке «Главная» появится кнопка «Конструктор ИД».

Ничего больше ставить не нужно: Node.js, сервер и панель — внутри установщика; интернет не нужен.
Программа ставится в `%LOCALAPPDATA%\Programs\KonstruktorID` без прав администратора, сервер запускается
сам при входе в Windows (без окна; журнал — `%LOCALAPPDATA%\KonstruktorID\server.log`). В меню «Пуск» →
«Конструктор ИД»: «Перезапустить сервер», «Папка данных», «Удалить Конструктор ИД». Обновление — запустить
установщик новой версии поверх; данные сохраняются.

Если раньше надстройка подключалась через «Общую папку» каталога и в Excel видны две кнопки — удалите
каталог в «Центре управления безопасностью» → «Доверенные каталоги надстроек».

**Сборка установщика** (разработчику): `node scripts/build-installer.mjs <путь к node.exe для Windows> <версия>`
— нужны Go 1.24+ и `zip`; результат в `dist/`.

## Установка из исходников (для разработки)

1. Установите **Node.js 22 LTS** (версия 22.13 или новее) с сайта nodejs.org
   (установщик по умолчанию).
**Быстрый способ:** дважды щёлкните `install-and-start.cmd` в папке проекта — он выполнит
`npm install`, `npm run build` и запустит сервер (окно сервера не закрывайте). Так же
запускайте его после распаковки новой версии. Затем выполните только шаг 4 (сертификат,
один раз). Пошагово — ниже.

2. Откройте **командную строку cmd** (Win+R → `cmd` → Enter; в начале строки не должно быть `PS`),
   перейдите в папку проекта (`cd /d "путь\к\konstruktor-id"`) и выполните:
   ```
   npm install
   npm run build
   ```
3. Запустите сервер:
   ```
   scripts\start.cmd
   ```
   В окне появится строка `Конструктор ИД: https://localhost:3443/addin/`.
   При первом запуске сервер создаёт папку данных
   `%LOCALAPPDATA%\KonstruktorID` (база, сканы, резервные копии, сертификаты).
4. Разрешите Windows доверять сертификату сервера. В PowerShell из папки проекта:
   ```
   powershell -ExecutionPolicy Bypass -File scripts\install-cert.ps1
   ```
   Windows спросит подтверждение — ответьте «Да». Этот корневой сертификат
   ограничен именами `localhost` и `127.0.0.1` и не годится для других сайтов.
5. Проверьте: откройте в браузере `https://localhost:3443/addin/index.html` —
   должна открыться панель без предупреждения о сертификате.

## Подключение надстройки к Excel

Excel загружает надстройки из «общей папки каталога». Её нужно один раз
настроить.

1. Создайте папку, например `C:\Addins`, и скопируйте в неё файл
   `packages\addin\dist\manifest.xml` (появляется после `npm run build`).
2. Откройте общий доступ к папке: правый щелчок по папке → «Свойства» →
   «Доступ» → «Общий доступ…» → «Поделиться». Запомните сетевой путь,
   например `\\ИМЯ-КОМПЬЮТЕРА\Addins`.
3. В Excel: «Файл» → «Параметры» → «Центр управления безопасностью» →
   «Параметры центра управления безопасностью» → «Доверенные каталоги
   надстроек». Вставьте сетевой путь в «URL-адрес каталога», нажмите
   «Добавить каталог», отметьте «Показывать в меню», нажмите «ОК».
4. Перезапустите Excel.
5. «Вставка» → «Мои надстройки» → вкладка «Общая папка» → «Конструктор ИД» →
   «Добавить». На вкладке «Главная» появится кнопка «Конструктор ИД».

## Книга объекта

Один объект — одна книга Excel. Откройте новую (или свою) книгу и панель конструктора:

1. Нажмите **«Создать книгу объекта»** — программа добавит листы с «умными таблицами»,
   выпадающими списками и подсветкой. Если в базе сервера есть данные из версии 0.2,
   программа предложит перенести их в книгу (сканы остаются на сервере, в книге —
   ссылки на них).
2. Заполняйте таблицы прямо на листах или в карточке строки на панели — изменения
   видны в обе стороны сразу.

**Панель:**
- **Разделы** открывают свой лист; переход на лист в Excel переключает раздел.
- **Функционал листа**: «+1», «+10» (строки под текущей), «Дублировать», «↑», «↓»,
  «Удалить» (с подтверждением; если на строку ссылаются другие листы — программа
  скажет сколько), «Важные столбцы» (галочки; пустые ячейки важных столбцов
  подсвечиваются розовым, заголовки — красным).
- **Функционал таблицы**: столбцы текущей таблицы; клик ставит курсор в ячейку этого
  столбца на текущей строке. Точка — важный столбец, красная — не заполнен.
- **Карточка строки**: все поля строки, выпадающие списки, календарь, выбор нескольких
  материалов галочками, загрузка скана. У материала — его документы качества и
  «Добавить документ»; у акта — переход к его схемам, материалам и ВОР и печать.
- **Переименование** материала, акта, организации или ФИО: программа предложит обновить
  ссылки на других листах.

Жёлтая ячейка — повтор значения, которое должно быть уникальным (наименование
материала, номер акта, краткое наименование организации). ФИО в «Представителях» может
повторяться: один человек бывает в нескольких ролях.

Если лист или таблицу программы удалили или переименовали, а также в книге прежней версии,
панель покажет «В книге нет таблиц…» и кнопку «Обновить разметку»: программа добавит
недостающие листы, таблицы и столбцы, данные не трогаются.

## Норматив

Вкладка «Норматив» в верхней строке — **справочник нормативов портала protect.gost.ru**: своды
правил, ГОСТ, правила, классификаторы, технические регламенты и основополагающие стандарты
(около 5000 документов) с наименованиями, статусами и числом страниц.

Программа не хранит и не распространяет тексты нормативов. В справочнике — только сведения из
открытых списков портала. Документ открывается напрямую с портала в отдельном окне Office; вход
на портал, если он нужен для просмотра, вы выполняете в этом окне сами.

- **«Обновить базу»** — сервер проходит по спискам разделов портала (несколько минут, нужен
  интернет). Пока идёт обновление, в панели виден ход: «Обновляю: СП, страница 12 из 38». Если
  связь пропала, уже скачанные разделы сохраняются, остальные остаются прежними.
- Поиск по обозначению и наименованию, кнопки разделов — фильтр.
- **«Читать»** — карточка документа на портале (там «Просмотр документа»).
- **«Карточка»** — сведения о документе в панели.
- **«В ячейку»** — вписывает обозначение в выделенную ячейку Excel (например, в п.6 акта):
  в пустую — как есть, в заполненную — через запятую; повтор не добавляется.

**Шаблоны ▾** — форма документов заказчика. Сейчас доступна одна — «СБД»; выбор хранится в
книге и передаётся в печать.

## Примеры и подсказки в новой книге

При создании книги без переноса данных в каждой таблице появляется **строка-пример** (серый
курсив, значение начинается с «Пример:»): она показывает, что и в каком виде вносить. Программа
такие строки не учитывает — в проверку и печать они не попадают. Замените значение «Пример: …»
своим — строка станет обычной; ненужный пример просто удалите.

При выделении любой ячейки таблицы Excel показывает **подсказку**: что вносить в этот столбец.
Та же подсказка — серым под полем в карточке строки.

## Кабельный журнал и протокол изоляции

Кабельный журнал и протокол сопротивления изоляции печатаются на акт — кнопками «КЖ» и
«Протокол» в карточке акта (рядом с АОСР, РИМ, ВД, ВОР). В них попадают кабели листа «Кабельный
журнал», у которых в столбце «Акт» указан этот акт.

Данные для протокола и штампа журнала — на листе **«Изоляция»**. Порядок заполнения:
1. «Электролаборатория» — наименование и адрес, свидетельство, руководитель, кто проводил испытания.
2. «СредстваИзмерений» — приборы (все попадают в протокол).
3. «ИзмеренияМарок» — в карточке кабеля или марки нажмите «Собрать марки из журнала», затем для
   каждой марки внесите назначение («RS-485»), напряжение мегаомметра, допустимое сопротивление
   и значения по парам жил («>1000»; пусто печатается «—»). Значения марки подставляются во все
   линии этой марки.
4. «ДокументыКабелей» — строка на акт: шифр и дата журнала, № протокола, даты измерений,
   температура, влажность; цель, нормативы, тексты о целостности и заключение уже заполнены
   по умолчанию.

Журнал печатается на листах А4 в рамке со штампом: если кабелей больше, чем помещается на лист,
добавляются листы с тем же штампом, «Лист» и «Листов» меняются. Протокол — альбомный, идёт
подряд на сколько угодно страниц.

## Реестр ИД и комплект в один PDF

1. В «Объекте» укажите **«Папка сканов»** (например `D:\Объект\Сканы`) и положите туда сканы
   схем, паспортов, сертификатов, свидетельств о поверке и т.д. (PDF, JPG, PNG). В столбцах
   «Скан» (схемы, документы качества, средства измерений, электролаборатория) достаточно имени
   файла; можно указать полный путь или прикрепить файл в карточке. Логотипы для титула —
   столбец «Логотип» в «Организациях» (PNG или JPG).
2. На листе **«Комплекты»** добавьте комплект: № реестра, Том, Часть, Корпус, перечень работ;
   галочки «Титул» и «Корешки», «Частей в томе». Ниже, в «Актах комплектов», перечислите акты
   комплекта по порядку.
3. В карточке комплекта нажмите **«Заполнить из актов»** — на листе «Реестр ИД» появятся строки
   в порядке образца СБД: ВОР, АОСР, РИМ, ВД, схемы, КЖ, протокол, свидетельства о поверке и
   лаборатории, документы качества. Строки можно править, переставлять, удалять и добавлять свои
   (вид «Прочее» со сканом — например, акт входного контроля).
4. **«Собрать комплект»**: программа проверит акты и сканы, напечатает документы, посчитает
   листы и откроет один PDF: титул → корешки → реестр с «л. N-M» → документы по порядку. Листы документов
   пронумерованы в правом нижнем углу — номер совпадает с «л.» в реестре (титул, корешки и реестр без номера).

## Печать документов

Документы печатаются в PDF через установленный в Windows **Microsoft Edge** — скачивать
ничего не нужно. На строке акта (лист «База актов») нажмите в панели «АОСР», «РИМ», «ВД»
или «ВОР». Сначала программа проверит данные акта: если что-то не заполнено или ссылается
на несуществующую строку, она покажет список «лист, строка, столбец» — клик переводит к
ячейке. Если всё в порядке, откроется окно предпросмотра с кнопкой «Скачать PDF».

**АВК** — акт входного контроля технических средств и материалов акта: материалы с производителем,
количеством (как в ВД) и документами качества; комиссия — подписанты ВОР акта. Номер по умолчанию —
«01/АОВ1.01.00» (последняя часть номера акта и окончание шифра), дата — начало работ; свои значения —
в столбцах «АВК: номер» и «АВК: дата» «Базы актов». В реестр ИД строка АВК попадает сама при
«Заполнить из актов».

Если Edge удалён, укажите путь к другому браузеру на основе Chromium (например, Google
Chrome) в переменной окружения `IDK_BROWSER` и перезапустите сервер.

## Контрольный пример

Чтобы посмотреть, как работает конструктор, можно загрузить пример — акт
№К32.В.СТ.АОВ1.01.00.1 (ООО «СБД»): организации, представители, 20 материалов с
документами качества, 6 схем и ВОР по этажам. Пример загружается в пустую базу сервера,
а затем переносится в новую книгу кнопкой «Создать книгу объекта»:

```
set IDK_DATA_DIR=C:\temp\idk-demo
npm.cmd run seed:sbd
npm.cmd start
```

## Проверка в Excel (версия 0.8)

1. Новая книга → «Создать книгу объекта» → «Перенести»: появились 9 листов, на
   «Базе актов» — акт АОВ1.01.00.1, на «ВОР» — 73 строки.
2. На листе «Материалы»: «+1», «+10», «Дублировать», «↑», «↓», «Удалить» — строки
   меняются, курсор идёт за строкой. То же на обычном листе вне таблиц.
3. «Важные столбцы»: снять/поставить галочку — меняется цвет заголовка и подсветка
   пустых ячеек.
4. «Функционал таблицы»: клик по столбцу — курсор в ячейке этого столбца.
5. Изменить поле в карточке — значение появилось в ячейке.
6. Изменить ячейку на листе — значение появилось в карточке.
7. Переименовать материал (в карточке или на листе) → «Обновить» — новое имя на листах
   «Документы качества», «Материалы в актах», «ВОР».
8. На материале «Добавить документ» — новая строка на «Документах качества».
9. Очистить номер документа качества и нажать «АОСР» — список ошибок, клик ведёт к ячейке.
10. Вернуть номер — печать АОСР, РИМ, ВД, ВОР открывает предпросмотр.
11. Удалить лист «ВОР» — «В книге нет таблиц: ВОР» → «Обновить разметку».
12. Верхняя строка: ⌂ возвращает к разделам, «Помощник» — экран-заготовка, значки справа
    неактивны; «Шаблоны ▾» — отмечен «СБД», выбор сохраняется после закрытия книги.
13. «Норматив» → «Обновить базу»: виден ход обновления, по окончании счётчики разделов
    (СП около 758, ГОСТ около 3421), «N документов, обновлён ДД.ММ.ГГГГ».
14. Выделите норматив → «Читать» открывает его карточку на protect.gost.ru; «Карточка» — сведения
    в панели.
15. Встаньте в ячейку п.6 акта на «Базе актов» → «В ячейку»: обозначение дописано через запятую;
    повторно — «Уже есть в ячейке».
16. Новая пустая книга → «Создать книгу объекта» (без переноса): в каждой таблице серая
    строка-пример; при выделении ячейки — подсказка; в карточке примера — плашка «Это
    строка-пример…». Замените «Пример: …» в наименовании материала — строка стала обычной.
17. На «Кабельном журнале» (пример АОВ1) нажмите «Собрать марки из журнала», заполните
    «Изоляция» по README. В карточке акта «КЖ» — один лист, ИТОГО 1618,9, штамп с шифром и
    подписями; «Протокол» — альбомный, 25 строк, приборы и подписи.
18. Удалите строку акта в «ДокументыКабелей» и нажмите «КЖ» — проверка сообщает, чего не хватает.
19. Добавьте кабелей так, чтобы их стало больше 30 — «КЖ» печатается на двух листах, в штампах
    «Лист 1/2» и «Листов 2».
20. Откройте книгу версии 0.6 → «Обновить разметку»: появились листы «Комплекты», «Реестр ИД»,
    столбцы «Логотип», «Скан» и поле «Папка сканов»; данные на месте. Пустой «Договор №»
    больше не подсвечивается розовым; одно ФИО в двух ролях — не жёлтое.
21. Документ качества без даты — РИМ печатается, в графе даты «б/д»; материал с паспортом и
    сертификатом записан в РИМ один раз. «Норматив» → «Вставлять: обозначение и наименование» →
    «В ячейку» дописывает `СП … "Наименование"`. «Настройки» (верхняя строка) → п.4 АОСР «Перед
    каждой схемой» — так печатается п.4; выбор сохраняется в книге.

## Автозапуск сервера

Чтобы сервер запускался вместе с Windows:
```
powershell -ExecutionPolicy Bypass -File scripts\register-autostart.ps1
```

## Данные и резервные копии

- Папка данных: `%LOCALAPPDATA%\KonstruktorID` (другую можно задать переменной
  окружения `IDK_DATA_DIR`).
- При каждом запуске сервер раз в сутки делает копию базы и сканов в
  `backups\ГГГГ-ММ-ДД` и хранит 30 последних копий.
- Чтобы восстановить данные:
  1. Остановите сервер (закройте его окно).
  2. В папке данных удалите файлы `db.sqlite-wal` и `db.sqlite-shm`, если они есть.
     Иначе SQLite применит к восстановленной базе изменения из старого журнала.
  3. Скопируйте `db.sqlite` и папку `files` из нужной копии в папку данных.

## Если что-то не работает

- **«Невозможно загрузить файл …\npm.ps1, так как выполнение сценариев отключено».**
  Команда запущена в PowerShell. Выполните её в cmd или пишите `npm.cmd` вместо `npm`
  (`npm.cmd install`, `npm.cmd run build`).
- **В панели «Сервер не запущен».** Запустите `scripts\start.cmd` и нажмите
  «Повторить».
- **«Порт 3443 занят: сервер уже запущен?»** Сервер уже работает в другом окне —
  второй запускать не нужно.
- **Панель пустая или предупреждение о сертификате.** Повторите шаг 4 установки
  и перезапустите Excel.
