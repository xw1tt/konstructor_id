# Конструктор ИД — инструкция пользователя

Версия 0.12 · 19.10.2026

## Что это за программа

«Конструктор ИД» собирает исполнительную документацию из одной книги Excel: данные объекта вносятся один раз, а акты, приложения, журналы и комплект для сдачи печатаются в PDF кнопками на панели.

Программа состоит из трёх частей:

- **Книга объекта** — обычный файл Excel с листами «Реквизиты», «Представители», «Материалы», «База актов» и другими. Все данные хранятся в ней: книгу можно копировать, пересылать и хранить как любой файл.
- **Панель «Конструктор ИД»** — надстройка справа в Excel. Она показывает карточку текущей строки, проверяет данные и запускает печать.
- **Сервер** — программа на вашем компьютере (окно «Konstruktor ID server»). Он печатает PDF через Microsoft Edge, собирает комплекты и обновляет справочник нормативов. Пока окно сервера открыто, печать работает.

Что печатает конструктор:

| Документ | Откуда берутся данные |
| --- | --- |
| АОСР — акт освидетельствования скрытых работ | «База актов», «Представители», «Реквизиты», «Исполнительные схемы» |
| РИМ — реестр использованных материалов | «Материалы в актах», «Документы качества» |
| ВД — ведомость смонтированного оборудования | «Материалы в актах», «ВОР» |
| ВОР — ведомость объёмов работ | «ВОР» |
| АВК — акт входного контроля | материалы акта и их документы качества |
| КЖ — кабельный журнал | «Кабельный журнал» |
| Протокол проверки сопротивления изоляции | «Кабельный журнал», «Изоляция» |
| Реестр ИД с титулом и корешками, комплект в одном PDF | «Комплекты», «Реестр ИД», сканы |
| Общий журнал работ, разделы 3 и 5 (приказ Минстроя № 1026/пр) | «База актов», «ОЖР Раздел 3», «ОЖР Раздел 5» |

Формы документов соответствуют образцам ООО «СБД».

## Установка и запуск

Программа ставится одним файлом «Установить Конструктор ИД <версия>.exe». Нужны Windows 10/11 и Excel 2019, 2021 или Microsoft 365; больше ничего ставить не нужно, интернет не нужен, права администратора не нужны.

### Установка

1. Запустите установщик. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае» (у установщика нет цифровой подписи).
2. На вопрос «Установить?» ответьте «Да». Когда Windows спросит про сертификат «Konstruktor ID Local CA», нажмите «Да» — без него панель не откроется. Сертификат действует только для адресов этого компьютера.
3. Закройте и снова откройте Excel. На вкладке «Главная» появится кнопка «Конструктор ИД» — она открывает панель справа.

Сервер работает в фоне без окна и сам запускается при входе в Windows. В меню «Пуск» → «Конструктор ИД» есть пункты «Перезапустить сервер», «Папка данных» и «Удалить Конструктор ИД».

### Обновление

Запустите установщик новой версии поверх старой и перезапустите Excel. Если панель предложит «Обновить разметку», нажмите — в книгу добавятся новые листы и столбцы, данные не изменятся.

### Где что лежит

| Что | Папка |
| --- | --- |
| Программа | `%LOCALAPPDATA%\Programs\KonstruktorID` |
| Данные сервера: прикреплённые сканы, справочник нормативов, резервные копии, журнал сервера `server.log` | `%LOCALAPPDATA%\KonstruktorID` |
| Книги объектов | там, куда вы их сохранили |

Удаление программы («Пуск» или «Установка и удаление программ») книги и папку данных не трогает.

## Панель

Панель всегда показывает то, что выделено в книге: раздел текущего листа, инструменты и карточку строки под курсором. Она не хранит своих данных — всё читается из книги и пишется в неё.

### Верхняя строка

| Кнопка | Что делает |
| --- | --- |
| ⌂ | Возврат к разделам книги |
| Норматив | Справочник нормативов protect.gost.ru |
| Помощник | Заготовка будущего помощника; значки справа пока неактивны |
| Шаблоны ▾ | Форма документов заказчика; сейчас одна — «СБД» |
| Настройки | Параметры программы |

### Разделы

Под верхней строкой — девять разделов: «Реквизиты», «Представители», «Акты», «Спецификация», «Материалы», «Схемы», «Кабельный журнал», «Комплекты», «ОЖР». Щелчок по разделу открывает его лист. У раздела из нескольких листов (например, «Акты»: «База актов», «Исполнительные схемы», «Материалы в актах», «ВОР») над карточкой появляются кнопки перехода между листами.

### Функционал листа

Работает со строками таблицы под курсором:

- **+1 / +10** — добавить строки под текущей; новая строка сразу получает значения по умолчанию (у акта — следующий номер, дату и подписантов ВОР);
- **Дублировать**, **↑ / ↓** — копия строки и перестановка; порядок строк важен: в нём материалы, схемы и строки реестра попадают в документы;
- **Удалить** — с подтверждением; если на строку ссылаются другие листы, панель скажет сколько и где;
- **Важные столбцы** — какие столбцы обязательны для печати (см. «Книга объекта»).

Если таблица отфильтрована, перед вставкой и перестановкой панель снимает фильтр, чтобы не задеть скрытые строки.

### Функционал таблицы

Список столбцов таблицы: точка — важный столбец, красная точка — он пуст в текущей строке. Щелчок переводит курсор в этот столбец.

### Карточка строки

Все поля строки с подсказками; «\*» — важное поле. Изменение в карточке сразу попадает в ячейку, и наоборот. Ссылки (организация, материал, акт) выбираются из списка, скан прикрепляется кнопкой.

При переименовании материала, акта, организации или ФИО панель предложит обновить ссылки на других листах. Под карточкой — действия раздела: у материала — его документы качества, у акта — переходы и печать, у комплекта — реестр и сборка.

## Книга объекта

Один объект — одна книга Excel. Данные лежат в «умных таблицах» на листах; панель связывает их по ключам: номеру акта, наименованию материала, краткому наименованию организации, ФИО.

### Создание книги

Откройте пустую книгу, панель и нажмите «Создать книгу объекта». Программа создаст листы и таблицы; в каждой таблице будет серая **строка-пример** (значение начинается с «Пример:»). Примеры не печатаются и не проверяются; замените их своими данными или удалите. При выделении любой ячейки Excel показывает подсказку, что в неё вносить.

### Листы

| Лист | Что на нём |
| --- | --- |
| Реквизиты | Объект (наименование, адрес, договор, участники, папка сканов, условия производства работ), Организации, Шифры рабочей документации |
| Представители | Подписанты по ролям, приказы, НРС, сроки полномочий |
| Материалы | Справочник материалов: марка, артикул, завод, единица |
| Документы качества | Паспорта, сертификаты, письма — с привязкой к материалам |
| База актов | Акты: номер, дата, шифр, работы, даты, нормативы, подписанты ВОР, АВК |
| Исполнительные схемы | Схемы и прочие документы п.4 АОСР |
| Материалы в актах | Какие материалы вошли в каждый акт |
| ВОР | Объёмы по этажам и участкам |
| Кабельный журнал | Кабели акта с трассами и длинами |
| Изоляция | Электролаборатория, средства измерений, измерения по маркам, шифры журналов и протоколов |
| Комплекты | Тома и части ИД, акты каждого комплекта |
| Реестр ИД | Строки реестра комплекта и сканы |
| ОЖР Раздел 3 | Общий журнал работ: работы по датам, условия, представитель |
| ОЖР Раздел 5 | Общий журнал работ: перечень исполнительной документации |

Скрытый лист «Списки» хранит значения выпадающих списков — не удаляйте его.

### Подсветка и важные столбцы

- **Красный заголовок** — важный столбец: без него документ не напечатается. Список важных столбцов меняется кнопкой «Важные столбцы».
- **Розовая ячейка** — пустое важное поле в заполненной строке. В «Объекте» обязательны только наименование объекта, застройщик и лицо, осуществляющее строительство; договор можно не указывать.
- **Жёлтая ячейка** — повтор значения, которое должно быть уникальным (наименование материала, номер акта, краткое наименование организации). ФИО представителей может повторяться: один человек бывает в нескольких ролях.
- **Серый заголовок** — служебный столбец (считается сам или заполняется панелью).

### Обновление разметки

Если книга создана прежней версией программы или лист случайно удалён, панель покажет предупреждение с кнопкой «Обновить разметку». Она добавляет недостающие листы, таблицы, столбцы и значения списков и заново настраивает подсказки; данные не меняются.

Не переименовывайте листы, таблицы и заголовки столбцов: по ним программа находит данные. Свои столбцы и формулы справа от таблиц добавлять можно.

## Порядок заполнения

Заполняйте книгу сверху вниз по разделам: сначала справочники объекта, потом акты, которые на них ссылаются. Ссылки выбираются из выпадающих списков — их значения должны уже быть в своих таблицах.

1. **Реквизиты → Организации.** Краткое и полное наименование, ОГРН, ИНН, адрес, телефон, СРО. Из них собирается шапка АОСР и реестра. В «Логотип» — файл PNG или JPG для титула комплекта.
2. **Реквизиты → Объект.** Наименование, адрес, город, договор (необязательно), застройщик, лицо, осуществляющее строительство, проектировщик, выполнивший работы по умолчанию, папка сканов.
3. **Реквизиты → Шифры.** Шифр РД, наименование раздела (идёт в заголовок ВОР, АВК и титул), проектировщик.
4. **Представители.** Роль, должность, ФИО, организация, документ о полномочиях, НРС. «Действует с/по» — в акт попадают только действующие на его дату. «Порядок» — очерёдность внутри роли. Если строка в акте должна быть особой — впишите её в «Текст для акта».
5. **Материалы.** Наименование (уникальное, без «;»), марка, артикул, завод, единица.
6. **Документы качества.** Материалы (несколько — через «; » или галочками на панели), тип, номер, дата (можно не указывать — будет «б/д»), срок действия, число листов, скан. У материала на панели есть кнопка «Добавить документ».
7. **База актов.** Номер акта без суффикса (программа добавит .АОСР, .РИМ, .ВД), дата, шифр, работы (п.1), листы и ревизия (п.2), даты работ (п.5), нормативы (п.6), разрешённые работы (п.7), подписанты ВОР. Новая строка «+1» сама получает следующий номер и сегодняшнюю дату.
8. **Исполнительные схемы.** Акт, вид («Схема» печатается как «Исполнительная схема №…», «Прочее» — как есть), номер, наименование, дата, скан. Порядок строк = порядок в п.4 АОСР.
9. **Материалы в актах.** Акт, материал, № позиции, количество. Пустое количество — программа возьмёт сумму из ВОР. Порядок строк = порядок в п.3, РИМ, ВД и АВК.
10. **ВОР.** Акт, этаж или участок, материал, объём. Материал должен быть в «Материалах в актах» этого акта. При нескольких этажах ВОР добавит итоговый раздел.

В карточке акта кнопки «Схемы», «Материалы», «ВОР» показывают число строк акта и фильтруют соответствующий лист по этому акту.

## Печать документов акта

Встаньте на строку акта на листе «База актов» и нажмите на панели кнопку документа: «АОСР», «РИМ», «ВД», «ВОР», «КЖ», «Протокол» или «АВК».

1. **Проверка.** Программа проверяет всё, что нужно документу: важные поля, даты и числа, ссылки на существующие строки, повторы. Ошибки показываются списком «лист, строка, столбец: что не так»; щелчок переводит к ячейке.
2. **Предпросмотр.** Если ошибок нет, открывается окно с PDF и ссылкой «Скачать PDF». Из окна документ можно сразу напечатать.

### Что учитывает печать

- **АОСР, п.3.** До пяти материалов — перечислены в акте с документами качества; больше пяти — ссылка на РИМ и ВД.
- **АОСР, п.4.** «Исполнительная схема» — перед первой из подряд идущих схем, как в образце СБД, или перед каждой — настройка шаблона («Редактор шаблонов», рядом с АОСР).
- **Подписанты** — из «Представителей» по ролям, действующие на дату акта, по «Порядку».
- **РИМ.** Один документ — одна строка; наименование материала пишется один раз над всеми его документами. Документ на несколько материалов — отдельной строкой с их перечнем. Документ без даты — «б/д».
- **ВД.** Количество из «Материалов в актах», а если пусто — сумма по ВОР.
- **АВК** — акт входного контроля материалов акта: производитель, количество, документы качества; комиссия — подписанты ВОР. Номер по умолчанию — «01/АОВ1.01.00» (последняя часть номера акта и окончание шифра), дата — начало работ. Свои значения — в столбцах «АВК: номер» и «АВК: дата» «Базы актов».

Если сервер не запущен, панель покажет «Сервер не запущен»: выберите «Пуск» → «Конструктор ИД» → «Перезапустить сервер» и нажмите кнопку печати ещё раз.

## Кабельный журнал и протокол изоляции

Кабельный журнал (КЖ) и протокол проверки сопротивления изоляции печатаются на каждый акт из кабелей этого акта.

1. **Лист «Кабельный журнал».** Одна строка — один кабель: акт, группа (заголовок в журнале, необязательно), обозначение, откуда и куда, направление по планам, марка и длина кабеля, труба и её длина, примечание.
2. **Лист «Изоляция»**, четыре таблицы:
   - «Электролаборатория» — наименование и адрес, свидетельство, руководитель, проводивший испытания, скан;
   - «Средства измерений» — приборы с поверкой; все попадают в протокол;
   - «Измерения марок» — напряжение мегаомметра, допустимое сопротивление и значения на марку кабеля; они подставляются во все линии этой марки;
   - «Документы кабелей» — строка на акт: шифр и дата журнала, № протокола, даты измерений, условия, цель, нормативы, заключение.
3. **Собрать марки.** Кнопка «Собрать марки из журнала» в карточке кабеля добавляет в «Измерения марок» все марки журнала, которых там ещё нет (с умолчаниями 500 В и 0,5 МОм). Остаётся вписать значения.
4. **Печать.** В карточке акта — «КЖ» и «Протокол».

- **КЖ** — листы А4 в рамке со штампом, по 30 строк. Если кабелей больше, добавляются листы с тем же штампом, «Лист» и «Листов» считаются сами. После кабелей — «ИТОГО» по каждой марке и «Всего». Подписи штампа — выполнившие работы и технадзор застройщика.
- **Протокол** — альбомные листы, строки идут подряд на любое число страниц, шапка таблицы на каждой. В конце — приборы и подписи лаборатории.

Перед печатью программа проверит: есть ли кабели акта, строка акта в «Документах кабелей», измерения на каждую марку, лаборатория и приборы.

## Реестр ИД и комплект в одном PDF

Комплект — это Том/Часть исполнительной документации из одного или нескольких актов. Программа собирает его в один PDF: титул → корешки → реестр → документы и сканы по порядку реестра.

1. **Сканы.** В «Объекте» укажите «Папка сканов» (например, `D:\Объект\Сканы`) и положите туда сканы схем, паспортов, сертификатов, свидетельств (PDF, JPG или PNG). В столбцах «Скан» достаточно имени файла; можно указать полный путь или прикрепить файл в карточке. Логотипы для титула — в «Организациях», столбец «Логотип».
2. **Комплект.** На листе «Комплекты»: № реестра, шифр (пусто — шифр первого акта), том, часть, корпус, перечень работ для титула, город, год, «Титул» и «Корешки» (да/нет), число частей в томе. Ниже, в «Актах комплектов», перечислите акты комплекта по порядку.
3. **Реестр.** В карточке комплекта нажмите «Заполнить из актов». На листе «Реестр ИД» появятся строки в порядке образца СБД: ВОР, АОСР, РИМ, ВД, схемы, КЖ, протокол, свидетельства о поверке и лаборатории, АВК, паспорта и сертификаты. Строки можно править, переставлять, удалять и добавлять свои (вид «Прочее» со сканом). Повторное «Заполнить» заменит строки комплекта — ручные правки пропадут, панель спросит подтверждение.
4. **Сборка.** «Собрать комплект» проверит акты и сканы, напечатает документы, посчитает листы и откроет один PDF. Если чего-то не хватает — список «Реестр ИД, строка N, «Скан»: Файл не найден…», щелчок ведёт к ячейке.

Листы документов нумеруются с ВОР = 1 в правом нижнем углу; номер совпадает с «л. N» в реестре. Титул, корешки и реестр не нумеруются. Графа «Листов» реестра берётся из документа, если не задана в строке. Собранный комплект доступен 30 минут: если окно предпросмотра пустое, нажмите «Открыть в браузере» или «Скачать PDF».

## Спецификация проекта (РКЦ)

Спецификация показывает по каждой позиции проекта: сколько всего по проекту, сколько закрыто актами и сколько осталось.

1. Раздел «Спецификация» на панели → «Загрузить из РКЦ» → выберите файл расчёта коммерческой стоимости (.xlsx) и лист (например, «д.с.1») → «Разобрать». Программа найдёт шапку «№ п/п — Наименование — Ед. изм. — Кол-во», разделы и позиции; итоги, НДС, аванс и цены не переносятся. Файл .xls сначала сохраните в Excel как «Книга Excel (*.xlsx)».
2. Проверьте предпросмотр: сколько позиций новых, изменённых и пропавших из РКЦ, и предупреждения (позиция без номера получает «б/н-1», повтор номера — «-2», пустое количество — 0). «Применить» запишет лист «Спецификация».
3. Доп. позиции добавляйте обычной строкой: свой номер (например, «доп-1»), «Источник» — «вручную».
4. Привяжите материалы: в «Материалах» столбец «№ п/п РКЦ» — номер позиции из списка. Кнопка «Подобрать № п/п» на листе «Материалы» предложит номера по сходству наименования и марки: отметьте верные и нажмите «Применить отмеченные». Сложные случаи можно отдать Claude — он заполнит столбец в присланной книге.
5. «Закрыто» и «Остаток» считаются сами: в «Закрыто» идёт «Кол-во» строки «Материалов в актах», а если оно пустое — сумма ВОР. Отрицательный остаток (закрыто больше, чем по проекту) — красным.
6. Карточка позиции в спецификации и карточка строки «Материалов в актах» показывают по проекту / закрыто / остаток и разбивку по актам. В карточке акта есть предупреждение о материалах без привязки — печать оно не блокирует.
7. «Обновить лист «Закрытие по актам»» строит отчёт: позиции по разделам и по столбцу на каждый акт — для сверки и для заказчика.

Новое доп. соглашение загружайте так же: позиции обновятся по № п/п, строки «вручную» и привязки материалов останутся, а позиции, которых нет в новом РКЦ, получат пометку «нет в РКЦ» в «Примечании».

## Общий журнал работ

Программа заполняет из актов разделы 3 и 5 общего журнала работ по форме приказа Минстроя России от 02.12.2022 № 1026/пр и печатает их листами для журнала. Титульный лист и разделы 1, 2, 4, 6 ведутся как обычно.

1. В «Объекте» заполните «Условия производства работ», например «Температура воздуха +18 °С, в помещении».
2. У актов должны быть «Начало работ» и «Окончание работ» и подписант «ВОР: от монтажников».
3. Раздел «ОЖР» на панели → «Заполнить из актов». Акты без дат работ панель покажет списком.
4. Проверьте листы и поправьте, что нужно, — например, условия в дни с другой погодой.
5. «Печать раздела 3» и «Печать раздела 5» откроют PDF по форме приказа.

| Лист | Что там | Как заполняется |
| --- | --- | --- |
| ОЖР Раздел 3 | Сведения о выполнении работ | Строка на каждый день работ актов, кроме воскресений; даты и номера идут подряд без повторов. Работы дня — п.1 актов по порядку «Базы актов», каждая с новой строки. Представитель — подписант ВОР от монтажников; если в день работают разные подрядчики — все. |
| ОЖР Раздел 5 | Перечень исполнительной документации | АОСР с приложениями (РИМ, ВД), исполнительные схемы, АВК, КЖ, протокол изоляции — по дате подписания, с должностями и фамилиями подписавших. |

Повторное «Заполнить из актов» строит оба листа заново: исправленные условия сохраняются для тех же дат, остальные ручные правки пропадают. Воскресенья и нерабочие праздничные дни (ст. 112 ТК РФ, с переносами по постановлениям Правительства) пропускаются автоматически; если работали в такой день — добавьте строку вручную. По порядку ведения журнала раздел 3 заполняется в день выполнения работ, раздел 5 — не позднее следующего дня после подписания документа.

## Норматив

Вкладка «Норматив» — справочник нормативов портала protect.gost.ru: своды правил, ГОСТ, правила, классификаторы, технические регламенты и основополагающие стандарты (около 5000 документов) с наименованиями и статусами. Тексты нормативов программа не хранит: документ открывается на самом портале.

- **Обновить базу** — загружает списки с портала (нужен интернет, несколько минут). Делайте это иногда, чтобы статусы были актуальны.
- **Поиск и разделы** — по обозначению и названию, фильтр по разделу.
- **Читать** — открывает карточку документа на protect.gost.ru; вход на портал вы выполняете сами. **Карточка** — сведения о документе на панели.
- **В ячейку** — вставляет норматив в активную ячейку (обычно п.6 акта) через запятую. Переключатель «Вставлять»: только обозначение («СП 76.13330.2016») или обозначение и наименование («СП 76.13330.2016 "Электротехнические устройства"»). Если норматив уже есть в ячейке, панель скажет «Уже есть в ячейке».

## Свои шаблоны

Шаблон — это набор документов с их формами. Встроенный «СБД» не меняется; свой шаблон делается из него кнопкой «Копия».

1. «Шаблоны ▾» → «Редактор шаблонов». Выберите «СБД», впишите имя (например, «Заказчик ПИК») и нажмите «Копия», затем «Выбрать для книги» — шаблон запомнится в книге объекта.
2. Документы шаблона: уберите ненужные («Убрать»), добавьте встроенные («Добавить встроенный») или свои — «Добавить свой документ» с названием и коротким кодом (например, «Акт гидравлических испытаний», код «АГИ»; номер документа будет «номер акта.АГИ»). Стрелки ↑↓ задают порядок кнопок печати и строк реестра ИД.
3. Своя форма — документ Word (.docx) или Excel (.xlsx) с метками вместо значений. Все метки — в «Шаблоны ▾» → «Поля для шаблона»: там видно, что подставится на выбранном акте, и есть кнопка «Копировать». Например: «Акт № {Акт.Номер АОСР} от {Акт.Дата}», «{Технадзор.Подпись}». Чтобы строка таблицы повторилась по материалам акта, начните её с «{#Материалы}» и закончите «{/Материалы}», а в ячейках поставьте «{Материал.Наименование}», «{Материал.Кол-во}» и т.д. Так же работают «Схемы» и «ВОР». Готовый файл — «Загрузить форму».
4. По образцу: если у вас есть заполненный документ, выберите внизу акт, по которому он заполнен, и нажмите «По образцу» у нужного документа. Программа заменит значения этого акта метками, а строку с первым материалом сделает повторяющейся. Если одно значение подходит к нескольким полям (например, одна дата у акта и окончания работ), выберите нужное в списке. «Скачать для проверки» откроет результат в Word; «Сохранить форму» прикрепит его к документу.
5. Печать: в карточке акта кнопки идут по документам шаблона; у документа со своей формой — значок ✎. PDF делает установленный Word или Excel — печать совпадает с тем, что вы видите в Word. Если Office нет, программа печатает сама и предупреждает, что форма может отличаться. После печати есть ссылка «скачать файл для правки» — заполненный .docx/.xlsx.
6. Свои документы попадают в реестр ИД («Заполнить из актов») и в комплект.

Шаблоны хранятся на этом компьютере и доступны в любой книге. «Выгрузить» сохраняет шаблон с формами в файл .idk-template, «Загрузить шаблон» — добавляет его на другом компьютере. Если книгу открыли там, где её шаблона нет, программа печатает по «СБД» и предупреждает об этом.

Ширина панели запоминается: после перезапуска Excel панель откроется той же ширины.

## Настройки и шаблоны

- **Шаблоны ▾** — шаблон книги («СБД» или свой), «Редактор шаблонов» и «Поля для шаблона» (см. «Свои шаблоны»). Выбор сохраняется в книге.
- **П.4 АОСР** — «Исполнительная схема» только перед первой схемой (как в образце СБД: «Исполнительная схема №1. …; №2. …») или перед каждой. Это настройка шаблона: «Редактор шаблонов», рядом с документом АОСР. У встроенного «СБД» — всегда перед первой; чтобы печатать перед каждой, сделайте копию шаблона.
- **Режим «В ячейку»** в «Нормативе» запоминается на компьютере пользователя, а не в книге.

## Если что-то не работает

| Что видно | Что сделать |
| --- | --- |
| Нет кнопки «Конструктор ИД» в Excel | Закройте все окна Excel и откройте снова. Не помогло — запустите установщик ещё раз. |
| Две кнопки «Конструктор ИД» | Осталось старое подключение через общую папку: удалите каталог в «Файл» → «Параметры» → «Центр управления безопасностью» → «Доверенные каталоги надстроек». |
| Панель пустая или «Не удалось открыть страницу» | Не запущен сервер или не установлен сертификат. «Пуск» → «Конструктор ИД» → «Перезапустить сервер»; не помогло — запустите установщик и ответьте «Да» на вопрос о сертификате. |
| «Сервер не запущен» на панели | «Пуск» → «Конструктор ИД» → «Перезапустить сервер». Причину покажет журнал `server.log` в «Папке данных». |
| «В книге нет таблиц…» или «Книга размечена прежней версией» | Нажмите «Обновить разметку» — данные не изменятся. |
| При печати — список ошибок | Щёлкните по строке списка — курсор перейдёт к ячейке; заполните и повторите печать. |
| «Не найден браузер для печати» | Печать идёт через Microsoft Edge — установите его или перезапустите сервер. |
| Окно предпросмотра пустое | «Открыть в браузере» или «Скачать PDF» вверху окна. |
| «Нет связи с порталом protect.gost.ru» | Проверьте интернет и повторите «Обновить базу» позже. |

### Данные и резервные копии

Главное — книга объекта: храните и копируйте её как обычный файл. Сервер раз в день делает резервную копию своих данных (прикреплённые сканы, справочник) в папку `backups` внутри «Папки данных». Сканы из «Папки сканов» объекта программа не копирует — храните их вместе с книгой.
