# Развёртывание облака «Конструктора ИД» (Yandex Cloud)

Версия 0.20 · 25.10.2026

Облако — это сервер компаний и пользователей: вход в панели Excel, баланс, консоль владельца. Ставится один раз на
виртуальную машину (ВМ) в Yandex Cloud. Свой домен не обязателен: без него адрес будет вида `51-250-10-20.sslip.io`,
HTTPS работает и с ним. Домен можно подключить позже.

Понадобится: аккаунт Yandex Cloud с платёжным аккаунтом, набор `Облако-Конструктор-ИД-0.20.zip` (файл «Облако.cmd» и
архив сервера), компьютер с Windows 10/11.

## 1. Создать ВМ

1. Консоль Yandex Cloud → **Compute Cloud** → **Виртуальные машины** → **Создать виртуальную машину**.
2. **Операционная система:** Ubuntu 24.04 LTS.
3. **Диск:** SSD, 30 ГБ. **Вычислительные ресурсы:** 2 vCPU, 4 ГБ памяти (для начала достаточно; при росте числа
   клиентов ресурсы увеличиваются без переустановки).
4. **Сетевые настройки → Публичный адрес:** «Автоматически». Лучше потом сделать адрес статическим (**Virtual Private
   Cloud** → **IP-адреса** → у адреса ВМ «Сделать статическим»), иначе после остановки ВМ он может смениться.
5. **Доступ:** логин администратора, например `admin`; **SSH-ключ** → «Добавить ключ» → «Сгенерировать ключ» — файл
   ключа скачается на компьютер. Сохраните его, например, в `C:\keys\idk`.
6. **Создать ВМ**. Дождитесь статуса `Running` и запишите **публичный IPv4-адрес**.

## 2. Открыть порты 80 и 443

Нужны для HTTPS (сертификат Let's Encrypt выпускается автоматически).

**Virtual Private Cloud** → **Группы безопасности** → группа ВМ (по умолчанию `default-sg-…`) → **Изменить** → в
**Входящий трафик** добавьте два правила: протокол TCP, порт `80`, источник `CIDR` `0.0.0.0/0`; то же для порта `443`.
Сохраните.

## 3. Установить — файлом «Облако.cmd»

Распакуйте `Облако-Конструктор-ИД-0.20.zip` в любую папку и запустите **«Облако.cmd»** → пункт **1 — установить**.
Он спросит:

- **публичный IP** ВМ (Yandex Cloud → ВМ → «Обзор»);
- **логин** на ВМ (тот, что указан при создании; по умолчанию `admin`);
- **файл SSH-ключа**, скачанный при создании ВМ, — перетащите его в окно (программа сохранит копию в `.ssh` и сама
  выставит права, без которых Windows не принимает ключ);
- **вашу почту** — вход владельца сервиса;
- **домен** — просто Enter, если домена нет.

Дальше всё делается само (5–10 минут): архив загружается на ВМ, ставится Docker, собирается и запускается сервер. В конце
на экране:

- **ссылка для первого входа владельца** — откройте её в браузере и задайте пароль (ссылка действует 7 дней);
- **адрес облака**, например `https://51-250-10-20.sslip.io` — его вводят в панели Excel;
- **консоль**: `https://51-250-10-20.sslip.io/console/`.

Тот же файл потом: **2** — обновить сервер новым архивом (положите новый `konstruktor-cloud-*.tar.gz` рядом), **3** —
новая ссылка для входа владельца (если забыли пароль), **4** — журнал сервера, **5** — скачать резервные копии базы.
Ответы запоминаются в `cloud-settings.txt` рядом с файлом.

Вручную (без «Облако.cmd»): в PowerShell `scp -i <ключ> konstruktor-cloud-0.20.tar.gz admin@<IP>:~`, затем
`ssh -i <ключ> admin@<IP>` и на сервере `tar -xzf konstruktor-cloud-0.20.tar.gz && cd konstruktor-cloud && sudo bash deploy/install.sh you@example.ru`.

Свой домен: создайте у регистратора A-запись `id.ваш-домен.ru` → IP ВМ, запустите «Облако.cmd» → 1 и укажите домен
(данные сохраняются).

## 4. Первые действия в консоли

1. **Тарифы** → новый тариф: название, ₽ за рабочее место в месяц, ₽ за 1000 токенов нейросети (пока не списываются),
   «проверяющие бесплатно».
2. **Компании** → добавить свою компанию: название, ИНН, рабочих мест → в карточке выберите тариф («без тарифа» —
   бесплатно, без списаний), **Пополнить** баланс (основание — номер счёта).
3. **Сотрудники** → пригласить администратора и инженеров: почта и роль → ссылка-приглашение, отправьте её сотруднику.
   Сотрудник по ссылке задаёт пароль.
4. В Excel у каждого: **Настройки → Облако** → адрес облака → **Сохранить** → на «⌂» — вход почтой и паролем.

Абонентская плата списывается раз в сутки: места × цена / дней в месяце. Баланс исчерпан — у компании «только чтение»:
книга работает, печать, комплект, ОЖР, свои формы и помощник недоступны, пока вы не пополните баланс. Кредитный лимит в
карточке компании позволяет работать в минус до этой суммы.

## 5. Обслуживание

- **Резервные копии** базы — раз в сутки в `~/konstruktor-cloud/deploy/backups` на сервере, хранятся 14 последних.
  Скачать на компьютер — «Облако.cmd» → 5.
  Для надёжности включите в Yandex Cloud снимки диска ВМ по расписанию (**Compute Cloud** → **Снимки дисков** →
  **Расписания**).
- **Обновление:** «Облако.cmd» → 2 с новым архивом рядом. Пароли, база и копии сохраняются.
- **Журнал сервера:** «Облако.cmd» → 4.
- **Восстановить пароль владельца:** «Облако.cmd» → 3 — новая ссылка задать пароль.
- **Персональные данные (152-ФЗ):** сервер в Yandex Cloud — на территории РФ. Перед продажей другим компаниям нужны
  уведомление Роскомнадзора и договор-поручение на обработку (этап 2 плана развития).

## Если что-то не работает

| Признак | Что проверить |
| --- | --- |
| Установка не печатает ссылку, сайт не открывается | Порты 80 и 443 в группе безопасности (п. 2); `sudo docker compose ps` в `deploy` — все службы `running` |
| Браузер пишет про сертификат | Подождите минуту после первого открытия — сертификат выпускается при первом обращении |
| Панель: «Нет связи с облаком» | Адрес в «Настройках → Облако» с `https://`; открывается ли он в браузере на этом ПК |
| Панель: «Запрос с чужого сайта отклонён» | Панель открыта не с `https://localhost:3443` — переустановите надстройку установщиком |
