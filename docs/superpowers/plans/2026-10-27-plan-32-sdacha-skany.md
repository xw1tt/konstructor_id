# План 32: проверка перед сдачей и документы качества по скану (0.28)

**Запрос:** автоматизировать ПТО дальше; пользователь согласился с приоритетами: проверка перед сдачей — **только
предупреждения** (ничего не блокирует), распознавание сканов документов качества.

- [x] `shared/check/predelivery.ts` — `checkActs(book, acts, today)`: сроки сертификатов на дату акта, даты документов и
  схем позже акта, материал без документов/количества, сканы и листы, даты работ, договор, подписанты без действующих
  полномочий (одно предупреждение на роль). Повтор ячейки — один раз.
- [x] Панель: `PreDelivery` в карточке акта и комплекта, жёлтый список (`IssueList tone="warn"`), переход к ячейке
  (виртуальные документы — к «Док.N»).
- [x] `shared/scan/docText.ts` — поля по правилам (вид, рег. номер ЕАЭС/РОСС, даты с периодом «с … по …», изготовитель),
  запрос к нейросети и разбор JSON, слияние.
- [x] Сервер: `scan/read.ts` — текст PDF (pdf.js, в установщике — `app/node_modules/pdfjs-dist`), иначе OCR Windows
  (PowerShell 5.1 + WinRT: Windows.Data.Pdf рисует страницы, Windows.Media.Ocr читает; язык ru, иначе — подсказка);
  `POST /api/files/:id/recognize`. Тесты с подменой OCR и нейросети; скрипт PowerShell проверен разбором.
- [x] Карточка материала: «Документ по скану…» → форма заполнена → «Добавить»; «Записать в материал» изготовителя;
  столбцы «Док.1–3» в карточке свёрнуты.
- [ ] Проверить OCR на Windows пользователя (в среде разработки Windows нет).
