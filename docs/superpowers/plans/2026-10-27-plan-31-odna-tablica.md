# План 31: одна таблица «Материалы» — материал, позиция РКЦ и документы качества

**Запрос:** 0.26 («материалы и документы рядом») — «не то»: объединить «Спецификацию», «Материалы» и «Документы
качества» в одну таблицу. Решение пользователя: три группы столбцов документов на материал, перенос старых книг, 0.27.

- [x] Схема 13: «Материалы» = материал + позиция РКЦ (№ п/п, раздел, кол-во по проекту, закрыто/остаток — формулы по
  материалу, источник, примечание) + `DOC_SLOTS` 1..3 («Док.k: вид/номер/дата/действует до/листов/наименование для
  реестра/скан»). «Спецификация» и «ДокументыКачества» — `virtual` (лист «Материалы»), листов у них нет.
- [x] `shared/workbook/virtual.ts`: вывод виртуальных строк (документ = вид+номер по всем строкам, позиция = № п/п)
  и запись в них — `withVirtualTables(store)`: чтение, правка (привязка/отвязка материалов документа), вставка в
  свободный «Док.N» (нет материала — строка создаётся; нет места — понятная ошибка), удаление (материал из актов не
  удаляется). Книга с настоящими старыми таблицами — как есть. Печать, реестр, закрытие спецификации, библиотека,
  помощник — без изменений.
- [x] `shared/workbook/mergeOld.ts`: план переноса старой книги (позиции — к материалам с тем же № п/п, без
  материала — новой строкой; документы — в группы их материалов; не поместилось — список проблем).
- [x] `applySpecInPlace`: повторная загрузка РКЦ — на месте по № п/п, материалы не удаляются и не переименовываются.
- [x] ExcelPort: публичные чтение/запись — через виртуальный слой, raw* — таблицы Excel; переход к ячейке, фильтр,
  номер строки листа — в «Материалах». «Обновить разметку»: старые таблицы → скрытый лист «Архив до 0.27» → удаляются
  (до дописывания столбцов: в 0.26 документы стояли справа) → строки сводятся в «Материалы» → опустевшие листы прочь;
  итог (`lastMerge`) — на панели. Тесты на модели Excel: книга 0.25, 0.26, четвёртый документ.
- [x] Панель: раздела «Спецификация» нет — РКЦ на экране «Материалы»; итог позиции — в карточке материала; карточка
  документов — «N из 3», «Удалить» у единственного материала; ошибки документов ведут к ячейке «Док.N: …».
- [x] Библиотека: материал — только свои столбцы; запись документов из библиотеки и отмена помощника — по ключу.
