# Документы в Excel рядом с PDF — дизайн

Статус: на согласовании.

## 1. Цель

Каждый документ, который печатается в PDF, можно сразу получить и файлом Excel (.xlsx). Excel-файл выглядит как бланк
PDF: те же строки, линии, подписи и таблицы, лист А4 с теми же полями. Его можно поправить вручную и распечатать
из Excel.

Решения пользователя:
- в Excel выводятся и встроенные бланки, и свои формы;
- файл Excel сохраняется рядом с PDF: один документ — один .xlsx;
- выводится всегда, без отдельной настройки.

## 2. Как это видит пользователь

В окне предпросмотра рядом с «Скачать PDF» всегда есть «Скачать Excel». Файлы называются одинаково, например
`19-0997-01-АОВ2.pdf` и `19-0997-01-АОВ2.xlsx`.

- **Встроенный бланк** (АОСР, РИМ/РМ, ВД, ВОР, АВК, КЖ, ИП, РП, протоколы и акты комиссии). Сервер собирает .xlsx по тем
  же данным, что и PDF, поэтому значения в PDF и Excel всегда совпадают.
- **Своя форма заказчика.** Если форма задана файлом .xlsx, кнопка отдаёт заполненный файл формы. Он уже собирается
  при печати, сейчас его можно скачать только в карточке акта. Если форма задана файлом .docx, кнопка называется
  «Скачать Word» и отдаёт заполненный .docx.
- **Комплект** (документы и сканы одним PDF). Кнопка «Скачать Excel (архив)» отдаёт .zip, в котором лежит .xlsx каждого
  документа комплекта. Сканы в Excel не переводятся.

## 3. Устройство

### Запись .xlsx (сервер, без новых зависимостей)

Модуль `server/src/xlsx/` пишет книгу из модели листа. Архив собирается уже имеющимся `zip/zip.ts`. Модель листа:

- столбцы с шириной в мм;
- ячейки: текст или число; шрифт Times New Roman, размер, полужирный, курсив; выравнивание и перенос; рамки;
  заливка;
- объединения ячеек;
- высота строк;
- разрывы страниц;
- лист А4 (книжный или альбомный) с полями как в PDF, «вписать по ширине», сквозные строки шапки таблицы;
- нумерация страниц в колонтитуле, где она есть в PDF (ВОР).

Excel не подбирает высоту объединённых ячеек сам, поэтому высоту строки задаём по оценке. Оценка: число строк
текста по ширине объединения и средней ширине знака шрифта, с небольшим запасом, чтобы текст не обрезался.

### Раскладка бланков

Каждый лист делится на сетку узких столбцов, например 36 столбцов по 5 мм на книжном листе с полями 20/10 мм. Из этой
сетки собираются элементы бланка:

- **абзац** — объединённая строка во всю ширину с переносом;
- **поле со значением** — полужирный курсив, нижняя линия под каждой строкой значения и мелкая подпись-пояснение
  строкой ниже;
- **строка «надпись + поле»** — номер и дата акта, «начала работ», «Дополнительные сведения», «Акт составлен в…»;
  значение стоит посередине линии, как в PDF;
- **таблица** — рамки, повтор шапки на каждой странице, объединение наименования для группы строк (РИМ);
- **подписи** — надпись роли, ФИО на линии во всю ширину, подпись «(фамилия, инициалы, подпись)».

Раскладка каждого бланка — отдельная функция рядом с его HTML-шаблоном и берёт те же данные: `AosrData`,
`RimData`, `TiData` и т. д. Повторяются и правила печати: в АОСР вторая страница начинается с п.1, пустой п.4
печатается как «Не требуется», в РМ сначала идут документы материала, потом материал.

### Маршруты

- `GET /api/print-jobs/:job/:doc?format=xlsx` — Excel встроенного бланка (имя файла — как у PDF, с `.xlsx`).
- `GET /api/form-jobs/:id/source` — уже есть: заполненная своя форма.
- `GET /api/kit-jobs/:job/xlsx` — архив .zip с Excel-файлами документов комплекта.

### Окно предпросмотра

Добавляется ссылка «Скачать Excel» («Скачать Word» для формы .docx, «Скачать Excel (архив)» для комплекта).
Файл собирается при нажатии: печать PDF от этого не замедляется.

## 4. Проверки (тесты)

1. Писатель .xlsx: архив открывается, в нём есть `workbook.xml`, `styles.xml` и листы; объединения, ширины, высоты,
   рамки, параметры страницы и сквозные строки записаны. Файл читается обратно нашим же разбором `forms/xlsx.ts`
   (текст ячеек совпадает).
2. Для каждого бланка: тексты всех значений из данных есть в листе; число подписантов и строк таблицы совпадает с PDF;
   для АОСР — разрыв страницы перед п.1, «Не требуется» в п.4, значения номера и дат по центру.
3. Маршруты: `format=xlsx` отдаёт xlsx с правильным именем; неизвестное или устаревшее задание — 404; архив комплекта
   содержит по файлу на документ.
4. Предпросмотр: ссылки на Excel и Word по виду документа.
5. Проверка «на глаз»: файлы открываются в LibreOffice (здесь) и переводятся в PDF; страницы сравниваются со
   снимками PDF тех же документов. Окончательная проверка — в Excel у пользователя.

## 5. Риски

- **Высота строк по оценке.** В Excel строка может получиться чуть выше, чем в PDF, или длинный текст обрежется.
  Оценку делаем с запасом и проверяем на длинных реальных данных: реквизиты организаций, представители, п.3 на десятки
  строк.
- **Разбиение на страницы.** Excel переносит страницы сам, и разрывы могут не совпасть с PDF. Обязательные разрывы
  (АОСР перед п.1) задаются явно.
- **Шрифт.** Шрифт Times New Roman нужен на компьютере. У пользователя он есть, в LibreOffice здесь его заменяет
  Liberation Serif с теми же размерами.

## 6. Объём и версия

Три плана:

- **26** — писатель .xlsx, элементы раскладки, АОСР в Excel, маршрут, ссылки в предпросмотре (в том числе для своих
  форм);
- **27** — остальные бланки СБД: РИМ, ВД, ВОР, АВК, КЖ, ИП;
- **28** — бланки «ТИ» (ВД, РМ, РП, КЖ), протоколы и акты комиссии, архив Excel для комплекта.
