# Планы 26–28: документы в Excel рядом с PDF — план реализации

**Spec:** `docs/superpowers/specs/2026-10-26-excel-vyvod-design.md`

**Architecture:** `server/src/xlsx/book.ts` — запись книги из модели листа (стили, объединения, высоты, разрывы,
сквозные строки, А4 «по ширине»); `xlsx/layout.ts` — элементы бланка (абзац, поле с линией, строка «надпись + поле»,
таблица, подписи) и перенос строк по ширинам знаков Times New Roman (`xlsx/metrics.ts`); раскладки бланков —
`print/xlsx/*.ts` на тех же данных, что HTML-шаблоны; маршруты `?format=xlsx`, `/source`, `/xlsx` комплекта; ссылки в
окне предпросмотра.

## Global Constraints

- Без новых зависимостей. Тесты `npm test` зелёные после каждого плана; коммиты с трейлерами сессии.
- Excel-форма документа выбирается так же, как PDF (`actDocFormFor`); имя файла — как у PDF, с `.xlsx`.
